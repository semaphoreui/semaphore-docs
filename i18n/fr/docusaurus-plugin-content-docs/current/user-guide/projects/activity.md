
# Activité

La page Activité fournit une piste d'audit complète de toutes les actions et de tous les événements qui se produisent dans votre projet. Cette fonctionnalité suit les activités des utilisateurs et les événements système, vous offrant une visibilité totale sur ce qui se passe dans votre projet.

![](/assets/project_activity.webp)

## Vue d'ensemble {#overview}

La page Activité affiche un flux chronologique de toutes les activités du projet, notamment :

- Les actions des utilisateurs (création, modification, suppression de ressources)
- Les événements et notifications du système
- Les changements d'accès et d'autorisations

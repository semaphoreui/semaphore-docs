# Statistiques

L'onglet **Statistiques** du tableau de bord du projet montre comment les tâches du projet se sont terminées au fil du temps.

![Statistiques du projet](/assets/project-stats.webp)

Le graphique **Statut des tâches** compte les tâches par jour selon leur statut final :

- **Success** : la tâche s'est terminée sans erreur.
- **Failed** : la tâche s'est terminée par une erreur.
- **Stopped** : la tâche a été arrêtée par un utilisateur.

Deux filtres au-dessus du graphique permettent de restreindre les données :

| Filtre | Options |
|---|---|
| **Période** | Semaine écoulée, Mois écoulé, Année écoulée |
| **Utilisateur** | Tous les utilisateurs, ou un seul membre du projet. Les tâches démarrées par des planifications et des intégrations n'ont pas d'utilisateur et ne sont incluses que dans **Tous les utilisateurs**. |

Le même graphique est disponible pour un modèle donné dans l'onglet **Détails** de la [page du modèle](../task-templates#template-page).

Pour voir les exécutions individuelles plutôt que des nombres agrégés, utilisez l'onglet [Historique](./history).

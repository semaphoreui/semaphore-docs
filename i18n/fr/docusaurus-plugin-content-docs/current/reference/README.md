# Référence

Cette section s'adresse au moment où vous savez déjà ce que vous cherchez et où il vous
faut le nom, le type ou la valeur par défaut exacts. Elle n'explique rien ; ce sont les
guides qui s'en chargent.

Les pages présentées ici sont **générées à partir du code source de Semaphore** à chaque
version : elles décrivent donc la version que vous exécutez, et non celle pour laquelle
quelqu'un a un jour écrit un tableau. Pour la même raison, elles ne sont publiées qu'en
anglais : une copie traduite serait obsolète dès la première modification d'une option.

## Dans cette section {#in-this-section}

# Introduction

Cette section s'adresse à toute personne qui découvre Semaphore, que vous soyez amené à
l'installer ou seulement à l'utiliser. Elle répond aux questions qui précèdent toute procédure :
ce que fait le produit, de quoi se compose un déploiement, ce que signifient les mots de l'interface,
et ce que vous devez préparer.

Lisez-la une fois, dans l'ordre, et le reste de la documentation n'aura plus besoin d'explication.
Rien ici ne vous demande d'installer quoi que ce soit — [Premiers pas](/getting-started) s'en
charge.

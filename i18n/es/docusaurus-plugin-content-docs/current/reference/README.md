# Referencia

Esta sección es para el momento en que ya sabes lo que quieres y necesitas el nombre,
el tipo o el valor por defecto exactos. No explica nada; de eso se encargan las guías.

Las páginas de aquí se **generan a partir del código fuente de Semaphore** en cada
versión, así que describen la versión que estás ejecutando y no la versión para la que
alguien escribió una tabla. Por esa misma razón se publican solo en inglés: una copia
traducida quedaría obsoleta en cuanto cambiara una opción.

## En esta sección {#in-this-section}

| Página | Qué cubre |

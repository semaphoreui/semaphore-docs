# Introducción

Esta sección es para cualquiera que conozca Semaphore por primera vez, tanto si va a
instalarlo como si solo va a usarlo. Responde a las preguntas previas a cualquier
procedimiento: qué hace el producto, de qué se compone una instalación, qué significan
las palabras de la interfaz y qué necesitas tener listo.

Léela una vez, en orden, y el resto de la documentación dejará de necesitar
explicaciones. Nada de lo que hay aquí te pide instalar nada — de eso se encarga
[Primeros pasos](/getting-started).

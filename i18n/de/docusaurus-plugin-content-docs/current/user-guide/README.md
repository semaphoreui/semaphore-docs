# Benutzerhandbuch

Erfahren Sie, wie Sie Semaphore im Alltag verwenden: Projekte erstellen, Tasks ausführen, Inventories, Schlüssel, Variablen und mehr verwalten.

## Hier beginnen {#start-here}

- Arbeit mit Projekten und Teams organisieren
- Repositories und Schlüsselspeicher verbinden
- Inventories und Variablengruppen definieren
- Task-Templates erstellen und Tasks nach Zeitplan ausführen

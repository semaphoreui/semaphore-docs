# Einführung

Dieser Abschnitt richtet sich an alle, die Semaphore zum ersten Mal begegnen, ganz
gleich ob Sie es installieren oder nur nutzen werden. Er beantwortet die Fragen, die
vor jeder Anleitung kommen: was das Produkt leistet, woraus eine Installation besteht,
was die Begriffe in der Oberfläche bedeuten und was Sie bereithalten müssen.

Lesen Sie ihn einmal von vorne bis hinten, und die übrige Dokumentation kommt ohne
weitere Erklärungen aus. Nichts davon verlangt eine Installation — das übernimmt
[Erste Schritte](/getting-started).

## In diesem Abschnitt {#in-this-section}

| Seite | Inhalt |
|---|---|
| [Was ist Semaphore](/introduction/what-is-semaphore) | Welches Problem es löst, für wen es gedacht ist und wann ein anderes Werkzeug besser passt. |
| [Architektur](/introduction/architecture) | Der Server, die Datenbank, der Dateicache, Runner und Executoren. |
| [Grundbegriffe](/introduction/concepts) | Projekte, Ressourcen, Templates und Tasks sowie ein Glossar aller Begriffe der Oberfläche. |
| [Sicherheitsmodell](/introduction/security-model) | Vertrauensgrenzen, wer Code zur Ausführung bringen kann und was verschlüsselt wird. |
| [Editionen](/editions) | Welche Funktionen zu Community, Pro und Enterprise gehören. |
| [Voraussetzungen](/introduction/prerequisites) | Host, Datenbank, Netzwerkzugriff und Zugangsdaten, die vorzubereiten sind. |

## Wo Sie beginnen {#where-to-start}

Beginnen Sie mit [Was ist Semaphore](/introduction/what-is-semaphore). Wenn Sie bereits
wissen, was es leistet, und es hier nur bereitstellen möchten, gehen Sie direkt zu
[Voraussetzungen](/introduction/prerequisites) und anschließend zur
[Installation](/admin-guide/installation).

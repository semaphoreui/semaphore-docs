# Devolutions Server skladište tajni <Enterprise />

Semaphore UI podržava Devolutions Server kao skladište za tajne. 

![](/assets/dvls1.webp)

Možete uneti sledeće opcije:
- **Devolutions Server URL** — adresa vašeg Devolutions servera.
- **Vault ID** — identifikator vault-a u kom se čuvaju tajne.
- **App Key** — ključ aplikacije koji se koristi za autentifikaciju.
- **Token** — token za autentifikaciju. Token može biti:
    - Sačuvan u bazi podataka.
    - Prosleđen preko promenljive okruženja.
    - Prosleđen preko fajla.

Skladište može raditi u režimu samo za čitanje.

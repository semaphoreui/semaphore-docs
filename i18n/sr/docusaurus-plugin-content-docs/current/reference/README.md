# Referenca

Ovaj odeljak je za trenutak kada već znate šta vam treba i potrebno vam je tačno ime,
tip ili podrazumevana vrednost. On ništa ne objašnjava; to rade vodiči.

Stranice ovde se **generišu iz izvornog koda Semaphore-a** pri svakom izdanju, pa
opisuju verziju koju pokrećete, a ne verziju za koju je neko nekada napisao tabelu. Iz
istog razloga objavljuju se samo na engleskom: prevedena kopija bi zastarela čim se
neka opcija promeni.

## U ovom odeljku {#in-this-section}

| Stranica | Šta obrađuje |
|---|---|
| [Opcije konfiguracije](/reference/configuration) | Svaki ključ datoteke `config.json` sa svojom promenljivom okruženja, tipom i podrazumevanom vrednošću. |
| [CLI referenca](/reference/cli) | Svaka `semaphore` komanda, potkomanda i opcija. |

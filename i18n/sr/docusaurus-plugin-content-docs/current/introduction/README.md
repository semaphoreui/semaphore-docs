# Uvod

Ovaj odeljak je namenjen svakome ko se prvi put susreće sa Semaphore-om, bilo da ćete
ga instalirati ili ga samo koristiti. Odgovara na pitanja koja dolaze pre bilo koje procedure:
šta proizvod radi, od čega se sastoji jedna instalacija, šta znače reči u interfejsu
i šta treba da imate spremno.

Pročitajte ga jednom, redom, i ostatak dokumentacije prestaje da zahteva objašnjenje.
Ovde se od vas ne traži da bilo šta instalirate — to radi [Prvi koraci](/getting-started).

| Stranica | Šta obrađuje |

| [Šta je Semaphore](/introduction/what-is-semaphore) | Problem koji rešava, kome je namenjen i kada bolje odgovara neki drugi alat. |
| [Arhitektura](/introduction/architecture) | Server, baza podataka, keš datoteka, runner-i i izvršioci. |
| [Osnovni pojmovi](/introduction/concepts) | Projekti, resursi, šabloni i zadaci, uz rečnik svih pojmova koje interfejs koristi. |
| [Bezbednosni model](/introduction/security-model) | Granice poverenja, ko može da pokrene izvršavanje koda i šta je šifrovano. |
| [Izdanja](/editions) | Koje funkcionalnosti pripadaju Community, Pro i Enterprise izdanju. |
| [Preduslovi](/introduction/prerequisites) | Host, baza podataka, mrežni pristup i kredencijali koje treba pripremiti. |

[Instalaciju](/admin-guide/installation).

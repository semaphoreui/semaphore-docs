# Riferimento

Questa sezione serve nel momento in cui sai già che cosa vuoi e ti occorre il nome, il
tipo o il valore predefinito esatto. Non spiega nulla; a questo servono le guide.

Le pagine qui presenti sono **generate dal codice sorgente di Semaphore** a ogni
release, quindi descrivono la versione che stai eseguendo e non quella per cui qualcuno
aveva scritto una tabella. Per lo stesso motivo sono pubblicate solo in inglese: una
copia tradotta sarebbe obsoleta al primo cambiamento di un'opzione.

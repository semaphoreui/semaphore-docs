# Introduzione

Questa sezione è pensata per chiunque incontri Semaphore per la prima volta, sia che
debba installarlo sia che debba solo usarlo. Risponde alle domande che precedono
qualsiasi procedura: che cosa fa il prodotto, di che cosa è composto un deployment,
che cosa significano le parole dell'interfaccia e che cosa devi avere pronto.

Leggila una volta, nell'ordine proposto, e il resto della documentazione non avrà più
bisogno di spiegazioni. Qui nulla ti chiede di installare qualcosa —
[Primi passi](/getting-started) serve a questo.

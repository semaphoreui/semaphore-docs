# Archivio di segreti Devolutions Server <Enterprise />

Semaphore UI supporta Devolutions Server come archivio per i segreti. 

![](/assets/dvls1.webp)

È possibile specificare le seguenti opzioni:
- **URL di Devolutions Server** — indirizzo del server Devolutions.
- **ID del Vault** — l'identificatore del vault in cui sono archiviati i segreti.
- **App Key** — la chiave applicativa utilizzata per l'autenticazione.
- **Token** — token di autenticazione. Il token può essere:
    - Archiviato nel database.
    - Fornito tramite una variabile d'ambiente.
    - Fornito tramite un file.

L'archivio può funzionare in modalità di sola lettura.

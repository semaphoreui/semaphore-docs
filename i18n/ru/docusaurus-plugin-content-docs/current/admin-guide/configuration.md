# Настройка

Semaphore читает настройки из файла конфигурации и переменных окружения. Онлайн-конфигуратор помогает подготовить их через форму. Выберите способ, подходящий для вашего сервера.

## В этом разделе {#in-this-section}

| Способ | Когда использовать |
|---|---|
| [Онлайн-конфигуратор](/admin-guide/configuration/online) | Вам нужна форма, которая создаёт конфигурацию и команды запуска для бинарной установки или Docker. |
| [Файл конфигурации](/admin-guide/configuration/config-file) | Вы хотите хранить настройки сервера в файле `config.json`. |
| [Переменные окружения](/admin-guide/configuration/env-vars) | Вы управляете настройками через Docker, описание службы или средства развёртывания. |

## Параметры конфигурации {#configuration-options}

Переменная окружения имеет приоритет над соответствующим значением в файле конфигурации. Встроенное значение по умолчанию применяется, если не задано ни то, ни другое. Если изменение файла не даёт результата, проверьте окружение процесса Semaphore.

[Справочник параметров конфигурации](/reference/configuration) содержит имена параметров, переменные окружения, типы и значения по умолчанию. Он генерируется из исходного кода Semaphore; для старого сервера используйте документацию его версии.

## Публичный URL {#1-how-to-configure-a-public-url-for-semaphore-ui}

Задайте в `web_host` (или `SEMAPHORE_WEB_ROOT`) адрес, который пользователи открывают в браузере. Например, если обратный прокси обслуживает Semaphore по адресу `https://example.com/semaphore`, укажите весь адрес вместе с `/semaphore`. Это публичный адрес, а не внутренний адрес подключения прокси.

## С чего начать {#where-to-start}

Для нового сервера откройте руководство по онлайн-конфигуратору выше и выполните шаги для бинарной установки или Docker. Для существующего сервера измените файл или переменные окружения его службы, затем перезапустите Semaphore.

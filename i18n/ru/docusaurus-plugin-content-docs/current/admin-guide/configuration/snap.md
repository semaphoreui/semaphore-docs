# Настройка Snap

Настройки Snap следует использовать, если Semaphore был установлен через Snap.

Чтобы увидеть список доступных опций, выполните следующую команду:

```bash
sudo snap get semaphore
```

Каждую из этих настроек можно изменить. Например, чтобы изменить порт Semaphore, выполните следующую команду:

```bash
sudo snap set semaphore port=4444
```

Не забудьте перезапустить Semaphore после изменения настройки:

```bash
sudo snap restart semaphore
```

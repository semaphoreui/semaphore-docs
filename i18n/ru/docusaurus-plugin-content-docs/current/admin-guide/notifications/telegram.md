# Telegram

### Предварительные требования {#pre-requisites}

Чтобы настроить отправку оповещений из Semaphore UI через Telegram, сначала необходимо выполнить несколько шагов на стороне Telegram.  Вам потребуется создать собственного бота, который будет принимать webhook, а также узнать ID чата, в который нужно отправлять сообщения.

#### Настройка бота {#bot-setup}

Проще всего создать собственного бота с помощью @BotFather.

1. В клиенте Telegram отправьте @BotFather сообщение `/start`.
1. Следуйте подсказкам, чтобы создать нового бота, и запишите токен авторизации, выданный на последнем шаге.  Примечание: этот токен секретный, обращайтесь с ним соответствующим образом.
1. Отправьте новому боту сообщение `/start`, чтобы запустить его и он мог получать сообщения.

#### ID чата {#chat-id}

1. В клиенте Telegram отправьте @RawDataBot любое сообщение.
1.  Скопируйте значение ключа `id` из объекта `chat`.

#### Проверка {#testing}

Проверить указанные выше настройки можно с помощью cURL следующим образом:

```
curl -X POST https://api.telegram.org/botYOUR_BOT_TOKEN/sendMessage \
  -d chat_id=YOUR_CHAT_ID \
  -d text="Test message from curl"
```

### Настройка {#configuration}

Используя ID чата и токен из предыдущих шагов, теперь можно настроить отправку оповещений в Telegram из Semaphore UI следующим образом:

```
telegram_alert: True
telegram_chat: <chat id>
telegram_token: <token>
```

Пример `config.json`:

```json
{
    "telegram_alert": true,
    "telegram_token": "64********:AAG****_rM6obyR********************",
    "telegram_chat":  "",
}
```


### ID чата для отдельных проектов {#per-project-chat-ids}

Для каждого проекта можно использовать уникальный ID чата.  Это позволяет разделять уведомления по проектам, вместо того чтобы отправлять их все в один чат. Данная настройка переопределяет глобальный ID чата, указанный выше.

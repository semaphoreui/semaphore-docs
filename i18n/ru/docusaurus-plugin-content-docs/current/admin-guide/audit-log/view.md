# Просмотр журнала аудита

Администраторы открывают **Audit log** из меню пользователя. Новые события идут первыми, по 50 на странице.

![Журнал аудита, новые события первыми](/assets/audit-log-list.png)

Нажмите на событие, чтобы увидеть все его поля. Кнопка копирования копирует событие в формате, в котором
Semaphore отправляет его в SIEM.

![Событие со всеми полями](/assets/audit-log-card.png)

## Фильтрация и экспорт <FeatureState feature="audit-log-filters" /> {#filter-export}

Фильтруйте по периоду, пользователю, виду события, результату, проекту или IP-адресу. В событии пользователь,
адрес, объект и проект являются ссылками, которые фильтруют журнал по ним.

![Журнал, отфильтрованный по адресу события](/assets/audit-log-filters.png)

Если сочетание фильтров находит мало событий, Semaphore ищет по две секунды за раз и показывает, как далеко в
прошлое он дошёл. Нажмите **Search older**, чтобы продолжить.

**Export** сохраняет все события, подходящие под фильтры, в файл CSV или JSON Lines. Каждый экспорт
записывается как событие `audit.log/export`.

![Экспорт в CSV или JSON Lines](/assets/audit-log-export.png)

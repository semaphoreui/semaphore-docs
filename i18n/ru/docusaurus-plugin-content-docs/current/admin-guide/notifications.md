# Уведомления

Semaphore сообщает о результатах задач в чаты и по электронной почте. Канал
настраивается один раз на сервере — в `config.json` или через переменные
окружения — и затем применяется ко всем проектам. То, какие задачи порождают
оповещение, определяется для каждого проекта и каждого шаблона в веб-интерфейсе.

## Как работает доставка {#how-delivery-works}

Отправку сообщения определяют три настройки, и все три должны её разрешать:

1. **Канал настроен на сервере.** У каждого провайдера свои параметры в
   `config.json`. См. страницу этого провайдера ниже.
2. **Проект разрешает оповещения.** *Allow alerts for this project* в
   [настройках проекта](/user-guide/projects/settings) — это главный
   переключатель. Если он выключен, ни один канал ничего не отправит об этом
   проекте.
3. **Шаблон запрашивает оповещение.** Шаблон задачи выбирает, оповещать ли об
   успешном выполнении, об ошибке или не оповещать вовсе, см.
   [Шаблоны задач](/user-guide/task-templates).

Используйте **Test alerts** в настройках проекта, чтобы отправить тестовое
сообщение по всем настроенным каналам, не запуская задачу.

## Каналы {#channels}

| Канал | Страница |
|---|---|
| Электронная почта (SMTP) | [Email](/admin-guide/notifications/email) |
| Telegram | [Telegram](/admin-guide/notifications/telegram) |
| Slack | [Slack](/admin-guide/notifications/slack) |
| Microsoft Teams | [Teams](/admin-guide/notifications/teams) |
| Rocket.Chat | [Rocket.Chat](/admin-guide/notifications/rocket) |
| DingTalk | [DingTalk](/admin-guide/notifications/ding) |
| Gotify | [Gotify](/admin-guide/notifications/gotify) |

Несколько каналов можно включить одновременно; каждый из них получает все
оповещения, прошедшие три проверки выше.

## Переопределения на уровне проекта {#per-project-overrides}

Telegram поддерживает отдельный чат для каждого проекта: задайте **Telegram Chat
ID** в [настройках проекта](/user-guide/projects/settings), чтобы направлять
оповещения одного проекта в чат, отличный от общесерверного. Остальные каналы
используют конфигурацию сервера для всех проектов.

## С чего начать {#where-to-start}

Сначала настройте один канал, включите *Allow alerts for this project* и нажмите
**Test alerts**. Как только придёт тестовое сообщение, включите оповещения в тех
шаблонах, которые вам важны.

# Уведомления

Semaphore сообщает о результатах задач в чаты и по электронной почте двумя способами:

- **Серверные каналы** настраиваются один раз на сервере — в `config.json` или через
  переменные окружения — и доступны всем проектам. Эта страница описывает их.
- **Оповещения проекта** — именованные назначения, которые участники проекта создают на
  вкладке [Оповещения](/user-guide/alerts) проекта: со своим чатом, вебхуком или
  получателями, привязанные к шаблонам и расписаниям.

## Как работает доставка {#how-delivery-works}

Для серверного канала отправку сообщения определяют три настройки, и все три должны её
разрешать:

1. **Канал настроен на сервере.** У каждого провайдера свои параметры в `config.json`.
   См. страницу этого провайдера ниже.
2. **Проект использует серверные каналы.** *Отправлять оповещения этого проекта в серверные
   каналы* на вкладке [Оповещения](/user-guide/alerts#server-channels) проекта — это
   главный переключатель. Если он выключен, серверные каналы ничего не отправят об этом
   проекте. На оповещения проекта этот переключатель не влияет.
3. **Шаблон запрашивает оповещение.** Шаблон с *настройками проекта по умолчанию* отправляет в
   серверные каналы; шаблон со своим списком оповещений — нет. Шаблон также может подавлять
   уведомления об успехе или ошибке, см. [Шаблоны задач](/user-guide/task-templates).

Чат-каналы сообщают об успехе, ошибке и задачах, ожидающих подтверждения; электронная почта —
только об ошибках. Оповещения проекта могут переопределять события для каждого назначения.

Используйте **Проверить все** на вкладке «Оповещения», чтобы отправить тестовое сообщение по
всем серверным каналам и всем включённым оповещениям проекта, не запуская задачу.

## Каналы {#channels}

| Канал | Страница |
|---|---|
| Электронная почта (SMTP) | [Email](/admin-guide/notifications/email) |
| Telegram | [Telegram](/admin-guide/notifications/telegram) |
| Slack | [Slack](/admin-guide/notifications/slack) |
| Microsoft Teams | [Teams](/admin-guide/notifications/teams) |
| Rocket.Chat | [Rocket.Chat](/admin-guide/notifications/rocket) |
| DingTalk | [DingTalk](/admin-guide/notifications/ding) |
| Gotify | [Gotify](/admin-guide/notifications/gotify) |

Несколько каналов можно включить одновременно; каждый из них получает все оповещения,
прошедшие три проверки выше. Те же провайдеры доступны для оповещений проекта: оповещения по
электронной почте и в Telegram используют SMTP-сервер и токен бота из конфигурации сервера, а
оповещение Gotify без собственных URL и токена использует общесерверную пару.

## Переопределения на уровне проекта {#per-project-overrides}

Telegram поддерживает отдельный чат для каждого проекта: задайте **Telegram Chat ID** на
вкладке [Оповещения](/user-guide/alerts#server-channels) проекта, чтобы направлять
сообщения серверных каналов одного проекта в чат, отличный от общесерверного. Для любого другого
назначения на уровне проекта создайте [оповещение проекта](/user-guide/alerts#project-alerts).

## С чего начать {#where-to-start}

Сначала настройте один канал, откройте вкладку «Оповещения» проекта, включите *Отправлять
оповещения этого проекта в серверные каналы* и нажмите **Проверить все**. Как только придёт
тестовое сообщение, настройте нужные шаблоны.

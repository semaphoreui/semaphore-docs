# Развёртывание в облаке

Semaphore можно запустить в любом облачном окружении, используя те же поддерживаемые способы установки:

- Виртуальные машины: установите через менеджер пакетов или бинарный файл и запускайте за обратным прокси, например NGINX. Для надёжности используйте управляемую базу данных (например, Amazon RDS, Cloud SQL).
- Контейнеры: разверните с помощью Docker или Docker Compose на виртуальной машине или в контейнерном сервисе. См. постоянные тома и настройку окружения в руководстве по Docker.
- Kubernetes: разверните с помощью официального Helm chart. Используйте облачные storage class'ы и управляемые базы данных.

Основные моменты:

- Настройте внешний URL и TLS на балансировщике нагрузки или обратном прокси.
- Храните конфиденциальные значения (учётные данные БД, секреты OAuth) в защищённом менеджере секретов или в Kubernetes Secrets.
- Для production используйте управляемые базы данных и включите регулярное резервное копирование.
- Размещайте runner'ы ближе к вашим рабочим нагрузкам, чтобы снизить задержки и исходящий трафик.

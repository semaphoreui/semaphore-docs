# Настройка Caddy

Caddy поддерживает websocket и по умолчанию включает только безопасные шифры TLS (TLS1.2 + TLS1.3), поэтому требуется минимальная конфигурация.

Пример конфигурации `/etc/caddy/Caddyfile`:

```
example.com {
    reverse_proxy 127.0.0.1:3000 {
        header_up X-Real-IP {client_ip}
    }
}
```

Если Caddy не может запросить TLS-сертификат через ACME (например, из-за файрвола или использования внутренних доменов), добавьте в конфигурацию `tls internal`.

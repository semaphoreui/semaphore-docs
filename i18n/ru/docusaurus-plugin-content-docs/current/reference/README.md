# Справочник

Этот раздел нужен в тот момент, когда вы уже знаете, что вам нужно, и ищете точное имя,
тип или значение по умолчанию. Он объясняет как можно меньше — это делают руководства.

Две страницы здесь **генерируются из исходного кода Semaphore**, поэтому описывают ту
версию, которую вы запускаете, а не ту, для которой кто-то когда-то составил таблицу.
По той же причине они публикуются только на английском языке: переведённая копия
устареет при первом же изменении любого параметра, и никто этого не заметит.

## В этом разделе {#in-this-section}

| [Параметры конфигурации](/reference/configuration) | Каждый ключ `config.json` с его переменной окружения, типом и значением по умолчанию. Генерируется автоматически. |
| [CLI](/reference/cli) | Команда `semaphore`: что делает каждая группа команд, как находится файл конфигурации и сгенерированный список всех команд и флагов. |
| [API](/reference/api) | Аутентификация по токену и вызов REST-эндпоинтов. |

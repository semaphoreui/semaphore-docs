# Справочник

Этот раздел нужен в тот момент, когда вы уже знаете, что вам нужно, и ищете точное имя,
тип или значение по умолчанию. Он ничего не объясняет — это делают руководства.

Страницы здесь **генерируются из исходного кода Semaphore** при каждом релизе, поэтому
описывают ту версию, которую вы запускаете, а не ту, для которой кто-то когда-то
составил таблицу. По той же причине они публикуются только на английском языке:
переведённая копия устареет при первом же изменении любого параметра.

# Хранилище секретов Devolutions Server <Enterprise />

Semaphore UI поддерживает Devolutions Server в качестве хранилища секретов. 

![](/assets/dvls1.webp)

Вы можете указать следующие параметры:
- **Devolutions Server URL** — адрес вашего сервера Devolutions.
- **Vault ID** — идентификатор хранилища (vault), в котором хранятся секреты.
- **App Key** — ключ приложения, используемый для аутентификации.
- **Token** — токен аутентификации. Токен может быть:
    - Сохранён в базе данных.
    - Передан через переменную окружения.
    - Передан через файл.

Хранилище может работать в режиме «только чтение».

# Проекты

Проект — основная единица разделения в Semaphore UI. Каждый ресурс, с которым вы работаете, принадлежит ровно одному проекту: шаблоны задач, задачи, инвентари, группы переменных, ключи, репозитории, интеграции, расписания, раннеры и участники команды.

Проекты независимы друг от друга, поэтому с их помощью можно организовать несвязанные системы в рамках одной установки Semaphore: разные команды, инфраструктуры, окружения или приложения.

## Навигация по проекту {#project-navigation}

После открытия проекта в левой боковой панели вверху отображается переключатель проектов, а ниже — все разделы проекта. Под названием проекта указана ваша роль в нём (например, `task_runner`). Роль определяет, какие разделы вы можете изменять; см. [Команды](./team).

![Панель проекта с вкладкой History](/assets/project-dashboard-history.webp)

| Раздел | Что содержит |
|---|---|
| **Dashboard** | Вкладки [История](./projects/history), [Статистика](./projects/stats), [Активность](./projects/activity), а для владельцев проекта — [Настройки](./projects/settings) |
| **Task Templates** | Описание того, что и как запускать: [Шаблоны задач](./task-templates) |
| **Workflows** (Pro) | Графы шаблонов с согласованиями и ветвлением: [Рабочие процессы](./workflows) |
| **Schedule** | Расписания запуска шаблонов в стиле cron: [Расписания](./schedules) |
| **Inventory** | Хосты и параметры подключения для Ansible, рабочие пространства для Terraform: [Инвентарь](./inventory) |
| **Variable Groups** | Переиспользуемые переменные и секреты, передаваемые в задачи: [Группы переменных](./environment) |
| **Key Store** | Зашифрованные учётные данные и внешние хранилища секретов: [Хранилище ключей](./key-store) |
| **Repositories** | Git-репозитории или локальные пути с вашими playbook и скриптами: [Репозитории](./repositories) |
| **Integrations** | Входящие вебхуки, запускающие задачи: [Интеграции](./integrations) |
| **Team** | Участники и их роли: [Команды](./team) |
| **Runners** (Pro) | Раннеры, привязанные к этому проекту: [Раннеры проекта](./projects/runners) |

Внизу боковой панели находятся переключатель тёмной темы, переключатель языка и [меню вашей учётной записи](./account).

## Создание проекта {#creating-a-project}

Создавать проекты могут администраторы. Обычные пользователи могут создавать проекты, только если включён серверный параметр `non_admin_can_create_project` (`SEMAPHORE_NON_ADMIN_CAN_CREATE_PROJECT`), см. [Конфигурация](/admin-guide/configuration).

1. Нажмите на название проекта вверху боковой панели и выберите **New Project**.
2. Заполните форму:

| Поле | Описание |
|---|---|
| **Project Name** | Отображаемое имя проекта. Его можно изменить позже в [Настройках](./projects/settings). |
| **Max number of parallel tasks** | Необязательное поле. Сколько задач этого проекта может выполняться одновременно. Оставьте пустым, чтобы не ограничивать. Задачи сверх лимита ждут в очереди со статусом `waiting`. |
| **Demo** | Заполняет новый проект демонстрационными данными: публичным репозиторием, инвентарём, ключом и несколькими шаблонами задач. Используйте, чтобы попробовать Semaphore без какой-либо настройки. |

3. Нажмите **Create**.

Пользователь, создавший проект, становится его **владельцем** (Owner).

## Переключение между проектами {#switching-between-projects}

Нажмите на название проекта вверху боковой панели, чтобы увидеть все проекты, участником которых вы являетесь, и переключиться между ними. Последний открытый проект запоминается в браузере.

## Резервное копирование и восстановление {#backup-and-restore}

Проект можно выгрузить в JSON-файл и импортировать в тот же или другой экземпляр Semaphore:

- **Экспорт**: откройте **Dashboard → Settings** и нажмите **Backup project** (см. [Настройки](./projects/settings)).
- **Импорт**: нажмите на название проекта в боковой панели, выберите **Restore project** и загрузите файл резервной копии.

Обе операции доступны и из командной строки, см. [CLI: Проекты](/admin-guide/cli/projects).

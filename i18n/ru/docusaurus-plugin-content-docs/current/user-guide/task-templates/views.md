# Представления

Представления (Views) группируют шаблоны задач по вкладкам над списком шаблонов. В новом проекте есть единственное представление **All**; вы можете добавить свои, например **Build**, **Deploy** и **Tools**, чтобы в проектах с большим числом шаблонов нужный находился быстро.

![Список шаблонов с вкладками представлений](/assets/templates-list.webp)

## Управление представлениями {#managing-views}

Изменять представления могут пользователи с ролью **Manager** и выше. Нажмите значок карандаша рядом с вкладками представлений, чтобы открыть диалог **Edit views**, затем нажмите **Add view** для создания новой вкладки. У каждого представления есть следующие настройки:

| Настройка | Описание |
|---|---|
| **Title** | Название вкладки. |
| **Type** | **Custom** показывает только шаблоны, назначенные этому представлению. **All** показывает все шаблоны проекта. |
| **Sort by** и **Reverse** | Порядок сортировки шаблонов во вкладке по умолчанию. |
| **Hidden** | Сохранить представление, но скрыть вкладку. |

Перетаскивайте представления в диалоге, чтобы изменить порядок вкладок. Удаление представления не удаляет его шаблоны: они остаются видимыми в представлении **All**.

## Назначение шаблона представлению {#assigning-a-template-to-a-view}

Откройте форму шаблона и выберите вкладку в поле **View**. Шаблон одновременно принадлежит одному пользовательскому представлению и всегда отображается в представлениях типа **All**.

## Столбцы {#columns}

Значок шестерёнки в правом верхнем углу списка шаблонов открывает выбор столбцов. Он применяется ко всем представлениям и сохраняется в вашем браузере.

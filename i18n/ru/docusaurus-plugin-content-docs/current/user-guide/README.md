# Руководство пользователя

Этот раздел предназначен для тех, у кого уже есть доступ к проекту Semaphore.
Всё, что описано здесь, происходит в веб-интерфейсе или через API проекта.
Установка сервера, его настройка и подключение провайдера идентификации описаны в
[Руководстве администратора](/admin-guide).

Работа в Semaphore выстроена в одну цепочку. **Проект** содержит всё остальное.
Внутри него вы регистрируете ресурсы, необходимые для запуска: **репозиторий** с
вашими playbook'ами или скриптами, **ключи** для доступа к нему и к вашим хостам,
**инвентарь** целевых машин и **группы переменных** со значениями и секретами.
**Шаблон задачи** объединяет всё это в описание того, что нужно запустить, а
каждый запуск такого шаблона — это **задача**. Расписания, рабочие процессы и
входящие вебхуки запускают шаблоны за вас.

## С чего начать {#where-to-start}

Если вас только что добавили в проект, прочитайте
[Проекты](/user-guide/projects), чтобы освоиться, а затем
[Задачи](/user-guide/tasks), чтобы запустить задачу и прочитать её лог. Если вы
настраиваете проект с нуля, следуйте таблице выше по порядку.

Совсем новичок в Semaphore? Начните с [Начала работы](/getting-started).

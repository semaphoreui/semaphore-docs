# Руководство пользователя

Узнайте, как использовать Semaphore в повседневной работе: создавать проекты, запускать задачи, управлять inventory, ключами, переменными и многим другим.

## С чего начать {#start-here}

- Организуйте работу с помощью проектов и команд
- Подключите репозитории и хранилище ключей
- Определите inventory и группы переменных
- Создайте шаблоны задач и запускайте задачи по расписанию

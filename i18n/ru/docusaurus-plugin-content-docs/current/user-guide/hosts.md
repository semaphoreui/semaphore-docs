# Hosts <FeatureState feature="hosts" />

Страница **Hosts** проекта перечисляет все хосты, до которых дошли задачи Ansible проекта, с результатом
последнего запуска на каждом. Откройте её, когда нужно узнать, какие хосты падают, до каких нельзя
достучаться и каких давно не касалась ни одна задача, не открывая логи задач по одному.

## Как это работает {#how-it-works}

Хосты не добавляются вручную. После каждой задачи Ansible Semaphore записывает каждый хост плея с
результатом на этом хосте: `ok`, `changed`, `failed` или `unreachable`. Учитываются задачи на сервере,
на раннерах и в исполнителях Docker или Kubernetes. Задачи других приложений, например Terraform или
Bash, хосты не добавляют.

Хост — это его имя в инвентаре. `web-01` в двух инвентарях — один хост, а `Web-01` — тот же хост, что и
`web-01`. Хост, до которого доходят задачи нескольких проектов, показывается в каждом проекте со своими
числами этого проекта. Хост остаётся в списке после того, как исчез из инвентаря, вместе со своей историей.

## Найти хост {#find-a-host}

- **Search** ищет хосты по имени.
- **Failing now** показывает хосты, на которых последний запуск завершился ошибкой. **Unreachable** показывает хосты,
  к которым Ansible не смог подключиться. **Not seen 30 days** показывает хосты, которых не касалась ни одна задача в течение месяца.
- **Template** сужает список до хостов одного шаблона.

Нажмите на хост, чтобы открыть его карточку: когда он был замечен впервые, сколько у него было запусков, сколько из последних
10 запусков завершились ошибкой, и задачи, которые до него дошли, с результатом на этом хосте. Нажмите на задачу, чтобы открыть
её лог.

Вкладка **Summary** задачи показывает то же для одного запуска: выберите **All servers**, чтобы увидеть все хосты
этой задачи с их счётчиками.

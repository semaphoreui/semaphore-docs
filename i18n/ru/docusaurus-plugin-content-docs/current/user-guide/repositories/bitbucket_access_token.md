# Токен доступа Bitbucket

Вы можете использовать токен доступа Bitbucket в Semaphore для доступа к репозиториям на Bitbucket.

Сначала нужно создать токен доступа для вашего репозитория Bitbucket с правами на чтение.

![](/assets/bitbucket_access_token_1.webp)

После создания вы увидите токен доступа. Скопируйте его в буфер обмена — он понадобится для создания **ключа доступа** в Semaphore.

![](/assets/bitbucket_access_token_2.webp)

1. Перейдите в раздел **Хранилище ключей** в Semaphore и нажмите кнопку **Новый ключ**.
2. Выберите `Login with password` в качестве типа ключа.
3. Введите `x-token-auth` в поле **Логин** и вставьте скопированный ранее ключ в поле **Пароль**. Сохраните ключ.<br/><br/>![](/assets/bitbucket_access_token_3.png)
4. Перейдите в раздел **Репозитории** и нажмите кнопку **Новый репозиторий**.
5. Введите HTTPS-URL репозитория (`https://bitbucket.org/path/to/repo`), укажите правильную ветку и выберите созданный ранее **ключ доступа**.<br/><br/>![](/assets/bitbucket_access_token_4.webp)

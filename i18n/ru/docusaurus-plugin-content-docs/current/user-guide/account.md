# Ваша учётная запись

Личные настройки находятся в меню учётной записи внизу боковой панели. Щёлкните по своему имени, чтобы открыть его.

![Меню учётной записи](/assets/user-menu.webp)

| Пункт | Описание |
|---|---|
| Версия | Версия Semaphore UI, работающая на сервере. |
| **API Tokens** | Персональные токены для [REST API](/admin-guide/api). |
| **Edit Account** | Ваше имя, логин, адрес электронной почты, настройка уведомлений и пароль. |
| **Sign Out** | Завершает сеанс. |

Рядом с меню находятся переключатель **тёмной темы** и переключатель **языка**. Обе настройки сохраняются в вашем браузере.

## Изменение учётной записи {#edit-account}

![Диалог изменения учётной записи](/assets/account-edit.webp)

Вкладка **Settings** содержит:

| Поле | Описание |
|---|---|
| **Name** | Отображаемое имя, которое видно в истории задач и в журнале активности. |
| **Username** | Имя для входа. |
| **Email** | Адрес, используемый для уведомлений по электронной почте и восстановления пароля. |
| **Send alerts** | Получать уведомления о задачах по электронной почте. Уведомления отправляются, только если настроен [канал электронной почты](/admin-guide/notifications/email) и проект разрешает уведомления. |

Метки рядом с флажками показывают ваши глобальные признаки: **Pro user** на экземпляре Pro, **Admin** для администраторов, **External** для учётных записей, управляемых через LDAP или OpenID Connect. Внешние пользователи не могут менять здесь логин и пароль.

Вкладка **Security** позволяет сменить пароль. Если администратор включил одноразовые пароли по времени, второй фактор настраивается на этой же вкладке.

![Вкладка Security](/assets/account-security.webp)

## Токены API {#api-tokens}

Выберите **API Tokens** в меню учётной записи. На странице перечислены ваши токены с датой создания, датой истечения и статусом. Ссылка **API Reference** открывает Swagger UI, встроенный в ваш экземпляр.

![Токены API](/assets/api-tokens.webp)

Нажмите **New Token**, задайте имя токена и выберите срок его действия. Значение токена показывается один раз после создания — скопируйте его сразу.

![Диалог создания токена](/assets/api-token-new.webp)

Используйте токен в заголовке `Authorization: Bearer`, см. [API](/admin-guide/api). Чтобы отозвать токен, удалите его из списка.

# Раннеры проекта <Pro />

Раннеры выполняют задачи не на сервере Semaphore, а на других машинах: ближе к целевой инфраструктуре, в другой сетевой зоне или с иным набором инструментов. **Глобальные раннеры** регистрируются администратором и обслуживают все проекты. **Раннеры проекта** принадлежат одному проекту, и ими управляет его команда в разделе **Runners**.

![Раннеры проекта](/assets/project-runners-list.webp)

| Столбец | Содержимое |
|---|---|
| Переключатель | Включает или отключает раннер. Отключённый раннер не получает задачи. Переключатель есть только у раннеров проекта; глобальными раннерами управляет администратор. |
| **Name** | Имя раннера. Метка **Global** обозначает раннеры, общие для всех проектов. |
| **Tag** | Теги раннера. Шаблоны с заданным **Runner tag** выполняются только на раннерах с этим тегом. |
| **Status** | **Online**, если раннер недавно обращался к серверу, иначе **Offline**. |

## Добавление раннера {#adding-a-runner}

Требуется роль **Manager** или выше. Нажмите **New Runner** и заполните форму.

<div class="dialog-screenshot dialog-screenshot--small">

![Диалог создания раннера](/assets/project-runner-new.webp)

</div>

| Поле | Описание |
|---|---|
| **Name** | Имя раннера, отображаемое в списке и в подробностях задачи. |
| **Tags** | Необязательное поле. Один или несколько тегов. Шаблон с заданным **Runner tag** выполняется только раннерами с этим тегом. |
| **Is default** | Раннеры с этим флагом берут также задачи шаблонов без тега раннера. Раннер без флага и без тегов задачи не получает никогда. |
| **Register** | Отмечено: раннер создаётся уже зарегистрированным, и диалог показывает токен раннера, который нужно указать в его конфигурации. Не отмечено: раннер создаётся незарегистрированным, и вы получаете одноразовый **регистрационный токен**; раннер регистрируется сам командой `semaphore runner register` или `semaphore runner start --auto-register`. |
| **Webhook** | Необязательный URL, который Semaphore вызывает при назначении задачи раннеру. Используйте его для запуска раннеров по требованию (one-off), например через облачную функцию. |
| **Max number of parallel tasks** | Необязательное поле. Сколько задач раннер может выполнять одновременно. |
| **Enabled** | Получает ли раннер задачи. |

После создания щёлкните по раннеру, чтобы снова увидеть его токен или регистрационный токен и скопировать фрагменты конфигурации.

## Установка раннера {#installing-the-runner}

Раннер — это тот же бинарный файл `semaphore` или Docker-образ `semaphoreui/runner`, запущенный в режиме раннера. Установка, файл конфигурации, команды регистрации, исполнители (local, Docker, Kubernetes) и вопросы безопасности описаны в руководстве администратора: [Раннеры](/admin-guide/runners) и [CLI: Раннеры](/reference/cli/runners).

## Направление задач на раннеры {#routing-tasks-to-runners}

1. Задайте раннеру один или несколько **тегов**, например `windows-qa-server`.
2. В форме шаблона укажите то же значение в поле **Runner tag**.
3. Задачи шаблона будут ждать в статусе `waiting`, пока раннер с этим тегом не окажется в сети.

Шаблоны без тега раннера направляются на раннеры с флагом **Is default**, включая глобальные раннеры по умолчанию. Раннер, выполнивший задачу, показан на вкладке **Details** [окна задачи](../tasks#task-window).

## Безопасность {#security}

- Раннеры подключаются к серверу, а не наоборот, поэтому раннер может работать за NAT или в частной сети.
- Каждый запрос от раннера аутентифицируется его токеном. Чтобы отозвать раннер, удалите или отключите его.
- Используйте HTTPS между раннерами и сервером, см. [Сетевая безопасность](/admin-guide/security/network).

# История

Вкладка **History** панели проекта перечисляет все задачи проекта, начиная с самых новых. Это представление открывается по умолчанию при входе в проект.

![История проекта](/assets/project-dashboard-history.webp)

## Столбцы {#columns}

| Столбец | Содержимое |
|---|---|
| **Task** | Номер задачи, шаблон, из которого она создана, и сообщение коммита использованной ревизии репозитория. Значок слева показывает приложение (Ansible, Terraform, Bash и так далее). |
| **Version** | Для [шаблонов сборки и развёртывания](../task-templates/build-deploy) — собранная или развёрнутая версия. Для остальных шаблонов только значок статуса. |
| **Status** | Текущий значок статуса, см. [Статусы задач](../tasks#task-statuses). |
| **User** | Кто запустил задачу. У задач, запущенных расписанием или интеграцией, пользователя нет. |
| **Start** | Дата и время начала в часовом поясе вашего браузера. |
| **Duration** | Сколько выполнялась задача. |

Список разбит на страницы. Щёлкните по номеру задачи или названию шаблона, чтобы открыть [окно задачи](../tasks#task-window) с логом, подробностями и сводкой. Щелчок по названию шаблона в заголовке окна задачи открывает страницу шаблона.

## Хранение задач {#task-retention}

По умолчанию все задачи и их логи хранятся бессрочно. Чтобы ограничить историю по каждому шаблону, задайте `max_tasks_per_template` в `config.json` или переменную окружения `SEMAPHORE_MAX_TASKS_PER_TEMPLATE`:

```json
{
  "max_tasks_per_template": 30
}
```

При достижении лимита самые старые задачи этого шаблона удаляются вместе с логами. Полный список параметров приведён в разделе [Конфигурация](/admin-guide/configuration).

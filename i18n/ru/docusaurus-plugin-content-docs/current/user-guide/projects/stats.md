# Статистика

Вкладка **Stats** панели проекта показывает, чем завершались задачи проекта с течением времени.

![Статистика проекта](/assets/project-stats.webp)

Диаграмма **Task Status** подсчитывает задачи по дням в разрезе итогового статуса:

- **Success**: задача завершилась без ошибок.
- **Failed**: задача завершилась с ошибкой.
- **Stopped**: задача была остановлена пользователем.

Два фильтра над диаграммой сужают выборку:

| Фильтр | Варианты |
|---|---|
| **Период** | Past week, Past month, Past year |
| **Пользователь** | All users или отдельный участник проекта. У задач, запущенных расписаниями и интеграциями, пользователя нет, и они попадают только в **All users**. |

Такая же диаграмма доступна для отдельного шаблона на вкладке **Details** [страницы шаблона](../task-templates#template-page).

Чтобы увидеть отдельные запуски вместо сводных чисел, откройте вкладку [История](./history).

# Настройки

Вкладка **Settings** панели проекта доступна **владельцам** проекта. На ней находятся общие параметры проекта и необратимые действия.

![Настройки проекта](/assets/project-settings-general.webp)

## Общие {#general}

| Поле | Описание |
|---|---|
| **Project Name** | Отображаемое имя, которое видно в переключателе проектов и в уведомлениях. |
| **Max number of parallel tasks** | Необязательное поле. Максимальное число задач этого проекта, которые могут выполняться одновременно. Оставьте пустым, чтобы не ограничивать. Задачи сверх лимита остаются в очереди со статусом `waiting`, пока не освободится место. |
| **Telegram Chat ID** | Необязательное поле. Отправляет уведомления по этому проекту в другой чат Telegram, отличный от заданного глобально. См. [Уведомления в Telegram](/admin-guide/notifications/telegram#per-project-chat-ids). |
| **Allow alerts for this project** | Главный переключатель уведомлений. Когда он выключен, ни один канал не отправляет уведомления о задачах этого проекта, даже если канал настроен на сервере. |

Кнопка **Test alerts** отправляет тестовое сообщение через каждый настроенный [канал уведомлений](/admin-guide/notifications), что позволяет проверить конфигурацию сервера без запуска задачи. Кнопка **Save** применяет изменения.

## Опасная зона {#danger-zone}

| Действие | Результат |
|---|---|
| **Backup project** | Скачивает JSON-файл с описанием проекта: шаблоны, инвентари, группы переменных, ключи (без значений секретов), репозитории, расписания, представления и интеграции. Восстановить его можно через **New Project → Restore project** или командой [`semaphore projects import`](/reference/cli/projects). |
| **Clear cache** | Удаляет все кешированные файлы проекта на сервере, например клонированные репозитории. Следующая задача клонирует репозитории заново. Действие необратимо. |
| **Delete project** | Удаляет проект вместе со всеми его ресурсами и историей задач. Отменить нельзя. |

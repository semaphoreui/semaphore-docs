
# PowerShell

Semaphore может выполнять PowerShell-скрипты на хостах Windows (или с Windows-runner’а). Для этого создайте шаблон задачи **PowerShell**.

## Создание шаблона PowerShell {#creating-a-powershell-template}

1. Перейдите в раздел **Шаблоны задач** и нажмите кнопку **Новый шаблон**.
2. Выберите **PowerShell** в качестве типа приложения.
3. Настройте шаблон:

| Поле | Описание |
|---|---|
| **Название** | Понятное название шаблона |
| **Репозиторий** | Репозиторий, содержащий ваш `.ps1`-скрипт |
| **Playbook / Скрипт** | Относительный путь к скрипту, например `scripts/deploy.ps1` |
| **Группы переменных** | Группы переменных, значения которых передаются как переменные окружения |

4. Нажмите **Создать**.
5. Нажмите **Запустить**, чтобы выполнить шаблон.

## Передача переменных в скрипты {#passing-variables-to-scripts}

Переменные из выбранных **Групп переменных** передаются как переменные окружения перед запуском скрипта. Обращайтесь к ним в PowerShell через `$env:VARIABLE_NAME`:

```powershell
Write-Host "Deploying to $env:TARGET_HOST"
```

## Запуск на хостах Windows {#running-on-windows-hosts}

Для шаблонов PowerShell требуется одно из двух:
- **Windows runner** — runner Semaphore, развёрнутый на хосте Windows. См. [Runners](/admin-guide/runners).
- Сам сервер Semaphore, работающий на Windows.

## Примечания {#notes}

- Скрипты выполняются в неинтерактивном режиме. Избегайте запросов, требующих ввода пользователя.
- Код выхода `0` означает успех; любой ненулевой код выхода помечает задачу как неудачную.

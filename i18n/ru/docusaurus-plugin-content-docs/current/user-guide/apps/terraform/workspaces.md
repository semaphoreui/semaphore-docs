# Рабочие пространства

![Вкладка Workspaces шаблона](/assets/template-workspaces.webp)

Semaphore имеет встроенную поддержку рабочих пространств Terraform, что позволяет управлять несколькими окружениями и конфигурациями в рамках одного проекта. Эта возможность помогает хранить отдельные файлы состояния для разных окружений, например development, staging и production.

## Возможности {#features}

- **Управление рабочими пространствами**: создание, переключение и удаление рабочих пространств прямо из интерфейса Semaphore.
- **Изоляция состояния**: каждое рабочее пространство хранит собственный файл состояния, что исключает конфликты между окружениями.
- **Переменные окружения**: настройка переменных окружения для конкретного рабочего пространства.
- **Выбор рабочего пространства**: выбор целевого рабочего пространства при запуске команд Terraform.

## Использование рабочих пространств в Semaphore {#using-workspaces-in-semaphore}

### Создание рабочего пространства {#creating-a-workspace}

В разделе **Workspaces** шаблона Terraform/OpenTofu, куда вы хотите добавить рабочее пространство, выполните следующие шаги:

1. Нажмите кнопку ➕.  
2. В появившемся меню выберите **New Workspace**.  
3. В модальном окне введите имя рабочего пространства и выберите SSH-ключ, который будет использоваться для клонирования модулей.  
4. Нажмите кнопку **Create**, чтобы добавить новое рабочее пространство в шаблон.  
5. Теперь это рабочее пространство можно использовать для запуска задач.


### Переключение рабочих пространств {#switching-workspaces}

Рабочее пространство по умолчанию для шаблона Terraform/OpenTofu задаётся нажатием кнопки **MAKE DEFAULT**.


### Переменные конкретного рабочего пространства {#workspace-specific-variables}

В настоящее время Semaphore не поддерживает переменные, привязанные к конкретному рабочему пространству.

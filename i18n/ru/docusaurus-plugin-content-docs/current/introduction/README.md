# Введение

Этот раздел предназначен для всех, кто впервые сталкивается с Semaphore, — независимо
от того, будете вы его устанавливать или только пользоваться им. Он отвечает на
вопросы, которые возникают до любой инструкции: что делает продукт, из чего состоит
установка, что означают слова в интерфейсе и что нужно подготовить.

Прочитайте раздел один раз, по порядку, и остальная документация перестанет нуждаться
в пояснениях. Здесь ничего не нужно устанавливать — этим занимается
[Начало работы](/getting-started).

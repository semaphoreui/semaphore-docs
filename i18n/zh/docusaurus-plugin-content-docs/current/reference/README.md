# 参考

本章面向你已经明确知道要什么、只需要精确的名称、类型或默认值的时刻。它尽量少作解释，
解释由各类指南负责。

这里有两个页面**由 Semaphore 源码生成**，因此描述的是你正在运行的版本，
而不是某人当初写表格时的版本。出于同样的原因，它们仅以英文发布：一旦某个选项首次发生变化，
译文副本立刻就会过时，而且没有人会注意到。

| 页面 | 涵盖内容 |
|---|---|
| [配置选项](/reference/configuration) | `config.json` 的每一个键，及其环境变量、类型和默认值。自动生成。 |

| [API](/reference/api) | 使用令牌认证并调用 REST 端点。 |

# 参考

本章面向你已经明确知道要什么、只需要精确的名称、类型或默认值的时刻。它不做任何解释，
解释由各类指南负责。

这里的页面在每次发布时都**由 Semaphore 源码生成**，因此描述的是你正在运行的版本，
而不是某人当初写表格时的版本。出于同样的原因，它们仅以英文发布：一旦某个选项发生变化，
译文副本立刻就会过时。

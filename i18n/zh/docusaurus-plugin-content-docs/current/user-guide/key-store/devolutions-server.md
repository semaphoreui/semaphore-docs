# Devolutions Server 密钥存储 <Enterprise />

Semaphore UI 支持将 Devolutions Server 用作密钥存储。 

![](/assets/dvls1.webp)

你可以提供以下选项：
- **Devolutions Server URL** — 你的 Devolutions 服务器地址。
- **Vault ID** — 存放密钥的保管库标识符。
- **App Key** — 用于认证的应用密钥。
- **Token** — 认证令牌。该令牌可以：
    - 存储在数据库中。
    - 通过环境变量提供。
    - 通过文件提供。

该存储可以以只读模式工作。

# 视图

视图将任务模板（Task Templates）分组为模板列表上方的选项卡。项目（Project）初始只有一个 **All** 视图；你可以添加自己的视图，例如 **Build**、**Deploy** 和 **Tools**，以便在拥有大量模板的项目中快速找到所需模板。

![带视图选项卡的模板列表](/assets/templates-list.webp)

## 管理视图 {#managing-views}

拥有 **Manager** 或更高角色的用户可以编辑视图。点击视图选项卡旁边的铅笔图标打开 **Edit views** 对话框，然后使用 **Add view** 创建新选项卡。每个视图有以下设置：

| 设置 | 说明 |
|---|---|
| **Title** | 选项卡标签。 |
| **Type** | **Custom** 只显示分配到此视图的模板。**All** 显示项目的所有模板。 |
| **Sort by** 和 **Reverse** | 选项卡中模板的默认排序方式。 |
| **Hidden** | 保留视图但隐藏选项卡。 |

在对话框中拖动视图可以更改选项卡的顺序。删除视图不会删除其中的模板，它们仍会显示在 **All** 视图中。

## 将模板分配到视图 {#assigning-a-template-to-a-view}

打开模板表单，在 **View** 字段中选择选项卡。一个模板同一时间只属于一个自定义视图，并且始终会列在 **All** 类型的视图中。

## 列 {#columns}

模板列表右上角的齿轮图标用于打开列选择器。它对所有视图生效，并保存在你的浏览器中。

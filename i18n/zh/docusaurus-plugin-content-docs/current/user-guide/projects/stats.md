# 统计

项目仪表盘的 **Stats** 选项卡显示项目（Project）中任务（Task）随时间的完成情况。

![项目统计](/assets/project-stats.webp)

**Task Status** 图表按天统计任务的最终状态：

- **Success**：任务无错误完成。
- **Failed**：任务以错误结束。
- **Stopped**：任务被用户停止。

图表上方的两个筛选器可以缩小数据范围：

| 筛选器 | 选项 |
|---|---|
| **Period** | Past week、Past month、Past year |
| **User** | 所有用户，或项目的单个成员。由计划任务和集成启动的任务没有用户，只包含在 **All users** 中。 |

在[模板页面](../task-templates#template-page)的 **Details** 选项卡中可以查看单个模板的同类图表。

要查看单次运行而不是汇总数字，请使用 [History](./history) 选项卡。

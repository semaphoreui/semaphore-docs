# 简介

本章面向所有初次接触 Semaphore 的人，无论你是要安装它，还是仅仅使用它。
它回答的是所有操作步骤之前的问题：这个产品做什么、一套部署由什么组成、界面中的词语
是什么意思，以及你需要准备好什么。

按顺序通读一遍，文档的其余部分就不再需要额外解释了。这里的内容不要求你安装任何东西
——[快速上手](/getting-started)才负责那部分。

| [什么是 Semaphore](/introduction/what-is-semaphore) | 它解决的问题、适合哪些人，以及什么情况下其他工具更合适。 |
| [架构](/introduction/architecture) | 服务器、数据库、文件缓存、运行器和执行器。 |
| [核心概念](/introduction/concepts) | 项目、资源、模板和任务，以及界面中所有术语的词汇表。 |
| [安全模型](/introduction/security-model) | 信任边界、谁可以让代码运行，以及哪些内容被加密。 |
| [版本](/editions) | 哪些功能属于 Community、Pro 和 Enterprise。 |
| [前置条件](/introduction/prerequisites) | 需要准备的主机、数据库、网络访问和凭据。 |

# クラウドへのデプロイ

Semaphore は、サポートされている同じインストール方法を使用して、任意のクラウド環境で実行できます。

- 仮想マシン: パッケージマネージャーまたはバイナリでインストールし、NGINX などのリバースプロキシの背後で実行します。信頼性のために、マネージドデータベース (Amazon RDS、Cloud SQL など) を使用してください。
- コンテナ: VM またはコンテナサービス上で Docker または Docker Compose を使用してデプロイします。永続ボリュームと環境設定については、Docker ガイドを参照してください。
- Kubernetes: 公式の Helm チャートを使用してデプロイします。クラウドのストレージクラスとマネージドデータベースを使用してください。

重要なポイント:

- 外部 URL と TLS は、ロードバランサーまたはリバースプロキシで設定します。
- 機密性の高い値 (DB の認証情報、OAuth のシークレット) は、安全なシークレットマネージャーまたは Kubernetes Secrets に保存します。
- 本番環境ではマネージドデータベースを使用し、定期的なバックアップを有効にします。
- レイテンシーと外部送信トラフィックを減らすために、ランナーをワークロードの近くに配置します。

# ホスト <FeatureState feature="hosts" />

管理者向けの **Hosts** ページには、すべてのプロジェクトのホストが一か所にまとめて表示され、そのうちどのホストがライセンスの **Nodes** にカウントされるかが分かります。左下の管理メニューを開き、**Hosts** を選択します。

ホストが一覧に入る仕組み、ステータス、検索、ホストカードはプロジェクトのページと同じです。詳しくは [ホスト](/user-guide/hosts) を参照してください。ここではホストはすべてのプロジェクトで 1 行にまとまり、そのカードにはホストに接続したプロジェクトとタスクが表示されます。

## ライセンスのカウント {#license-count}

ライセンスには一定数のホストが含まれます。**サブスクリプションと請求** の **Nodes** 行には、使用中の数が `42 / 50` のように表示されます。直近 1 か月以内に Ansible タスクが接続し、誰も廃止していないホストが使用中です。一度も接続できなかったホストは使用中になりません。

使用中でないホストは、一覧に **Not counted** と表示されます。次にタスクが接続すると、自動的にカウントに戻ります。

使用中のホストがライセンスに含まれる数を超えると、**Nodes** 行が赤くなって **(limit exceeded)** と表示され、このページに警告が表示されます。管理しなくなったホストを廃止するか、ライセンスを拡張してください。詳しくは [ライセンスの有効化](/admin-guide/license) を参照してください。

## ホストを廃止する {#decommission}

インフラストラクチャからホストを削除した場合は、その行の末尾にある **Decommission** をクリックして確定します。ホストはすぐにカウントから外れ、**Decommissioned** と表示され、すべてのプロジェクトで履歴は保持されます。後でタスクが再びそのホストに接続すると、Semaphore はマークを外し、ホストは再び使用中になります。

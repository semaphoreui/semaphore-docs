# ホスト <FeatureState feature="hosts" />

プロジェクトの **Hosts** ページには、そのプロジェクトの Ansible タスクが接続したすべてのホストが、最後の実行結果とともに表示されます。タスクのログを一つずつ開かなくても、失敗しているホスト、接続できないホスト、しばらくどのタスクも接続していないホストを確認できます。

## 仕組み {#how-it-works}

ホストを手動で追加する必要はありません。Ansible タスクが終わるたびに、Semaphore はプレイ内の各ホストとそのホストでの結果 (`ok`、`changed`、`failed`、`unreachable`) を記録します。サーバー、ランナー、Docker や Kubernetes の実行環境で実行したタスクはすべて対象です。Terraform や Bash など他のアプリケーションのタスクではホストは追加されません。

ホストはインベントリ上の名前で識別されます。2 つのインベントリにある `web-01` は 1 つのホストで、`Web-01` は `web-01` と同じホストです。複数のプロジェクトのタスクが接続するホストは、各プロジェクトに、そのプロジェクト自身の数値で表示されます。ホストがインベントリから外れても、履歴とともに一覧に残ります。

## ホストを探す {#find-a-host}

- **Search** で名前からホストを検索します。
- **Failing now** は最後の実行が失敗したホストを表示します。**Unreachable** は Ansible が接続できなかったホストを表示します。**Not seen 30 days** は 1 か月間どのタスクも接続していないホストを表示します。
- **Template** で一覧を 1 つのテンプレートのホストに絞り込みます。

ホストをクリックするとカードが開きます。最初に確認された日時、実行回数、直近 10 回の実行のうち失敗した回数、そのホストに接続したタスクとこのホストでの結果が表示されます。タスクをクリックするとそのログが開きます。

タスクの **Summary** タブでは、1 回の実行について同じ内容を確認できます。**All servers** を選択すると、そのタスクのすべてのホストがカウンターとともに表示されます。

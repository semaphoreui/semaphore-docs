# ビュー

ビューは、テンプレートの一覧の上にあるタブにタスクテンプレートをグループ化します。プロジェクトには最初から **すべて** のビューが 1 つ用意されており、たとえば **ビルド**、**デプロイ**、**ツール** のように独自のビューを追加できます。これにより、テンプレートが多いプロジェクトでも目的のテンプレートを素早く見つけられます。

![ビューのタブが表示されたテンプレートの一覧](/assets/templates-list.webp)

## ビューの管理 {#managing-views}

**マネージャー** 以上のロールを持つユーザーはビューを編集できます。ビューのタブの横にある鉛筆アイコンをクリックすると **ビューの編集** ダイアログが開き、**ビューを追加** で新しいタブを作成できます。各ビューには次の設定があります。

| 設定 | 説明 |
|---|---|
| **タイトル** | タブのラベルです。 |
| **種類** | **カスタム** はこのビューに割り当てられたテンプレートのみを表示します。**すべて** はプロジェクトのすべてのテンプレートを表示します。 |
| **並び替え** と **逆順** | タブ内のテンプレートの既定の並び順です。 |
| **非表示** | ビューは残したまま、タブを非表示にします。 |

ダイアログ内でビューをドラッグすると、タブの順序を変更できます。ビューを削除してもテンプレートは削除されず、**すべて** のビューに引き続き表示されます。

## テンプレートをビューに割り当てる {#assigning-a-template-to-a-view}

テンプレートのフォームを開き、**ビュー** のフィールドでタブを選択します。テンプレートは同時に 1 つのカスタムビューにのみ属し、**すべて** の種類のビューには常に表示されます。

## 列 {#columns}

テンプレートの一覧の右上隅にある歯車アイコンから、表示する列を選択できます。この設定はすべてのビューに適用され、ブラウザーに保存されます。

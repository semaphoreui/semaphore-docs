# プロジェクトのランナー (Pro)

ランナーは、Semaphore サーバー以外のマシンでタスクを実行します。対象インフラの近く、別のネットワークゾーン、あるいは異なるツールチェーンを備えた環境などです。**グローバルランナー** は管理者が登録し、すべてのプロジェクトで利用できます。**プロジェクトのランナー** は 1 つのプロジェクトに属し、そのプロジェクトのチームが **ランナー** セクションで管理します。

![プロジェクトのランナー](/assets/project-runners-list.webp)

| 列 | 内容 |
|---|---|
| スイッチ | ランナーの有効・無効を切り替えます。無効なランナーにはタスクが割り当てられません。スイッチがあるのはプロジェクトのランナーのみで、グローバルランナーは管理者が管理します。 |
| **名前** | ランナーの名前です。**グローバル** のバッジは、すべてのプロジェクトで共有されるランナーを示します。 |
| **タグ** | ランナーのタグです。**ランナータグ** が設定されたテンプレートは、そのタグを持つランナーでのみ実行されます。 |
| **ステータス** | ランナーが最近サーバーをポーリングしている場合は **オンライン**、そうでない場合は **オフライン** です。 |

## ランナーの追加 {#adding-a-runner}

**マネージャー** 以上のロールが必要です。**新しいランナー** をクリックし、フォームに入力します。

<div style={{maxWidth: 420}}>

![新しいランナーのダイアログ](/assets/project-runner-new.webp)

</div>

| フィールド | 説明 |
|---|---|
| **名前** | 一覧とタスクの詳細に表示されるランナーの名前です。 |
| **タグ** | 任意です。1 つ以上のタグを指定します。**ランナータグ** が設定されたテンプレートは、そのタグを持つランナーによってのみ実行されます。 |
| **既定にする** | このフラグが付いたランナーは、ランナータグが設定されていないテンプレートのタスクも引き受けます。このフラグもタグもないランナーには、タスクが割り当てられることはありません。 |
| **登録** | オンの場合、ランナーは登録済みとして作成され、ダイアログにランナーの設定へ記載するランナートークンが表示されます。オフの場合、ランナーは未登録として作成され、1 回だけ使用できる **登録トークン** が発行されます。ランナーは `semaphore runner register` または `semaphore runner start --auto-register` で自身を登録します。 |
| **Webhook** | 任意です。タスクがランナーに割り当てられたときに Semaphore が呼び出す URL です。たとえばクラウド関数を使って、オンデマンド（ワンオフ）のランナーを起動するために使用します。 |
| **並列タスクの最大数** | 任意です。ランナーが同時に実行できるタスク数を指定します。 |
| **有効** | ランナーがタスクを受け取るかどうかです。 |

作成後にランナーをクリックすると、トークンまたは登録トークンを再度確認し、設定のスニペットをコピーできます。

## ランナーのインストール {#installing-the-runner}

ランナーは、ランナーモードで起動した同じ `semaphore` バイナリ、または `semaphoreui/runner` の Docker イメージです。インストール、設定ファイル、登録コマンド、エグゼキューター（local、Docker、Kubernetes）、セキュリティについては、管理者ガイドの[ランナー](/admin-guide/runners)と [CLI: ランナー](/reference/cli/runners)で説明しています。

## タスクのランナーへの振り分け {#routing-tasks-to-runners}

1. ランナーに 1 つ以上の **タグ**（たとえば `windows-qa-server`）を設定します。
2. テンプレートのフォームで **ランナータグ** に同じ値を設定します。
3. そのテンプレートのタスクは、該当するタグを持つランナーがオンラインになるまで `waiting` のステータスで待機します。

ランナータグのないテンプレートは、グローバルな既定のランナーを含む、**既定にする** が設定されたランナーに振り分けられます。タスクを実行したランナーは、[タスクウィンドウ](../tasks#task-window)の **詳細** タブに表示されます。

## セキュリティ {#security}

- 接続は常にランナーからサーバーへ行われ、その逆はありません。そのため、ランナーは NAT の背後やプライベートネットワーク内に配置できます。
- ランナーからのすべてのリクエストは、そのトークンで認証されます。ランナーを無効化するには、削除するか無効にしてください。
- ランナーとサーバーの間では HTTPS を使用してください。[ネットワークセキュリティ](/admin-guide/security/network)を参照してください。

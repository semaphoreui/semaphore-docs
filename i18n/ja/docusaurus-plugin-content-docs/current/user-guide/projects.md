# プロジェクト

プロジェクトは、Semaphore UI における分離の主要な単位です。扱うすべてのリソース（タスクテンプレート、タスク、インベントリ、変数グループ、キー、リポジトリ、インテグレーション、スケジュール、ランナー、チームメンバー）は、必ず 1 つのプロジェクトに属します。

プロジェクトは互いに独立しているため、1 つの Semaphore インストール内で無関係なシステム（異なるチーム、インフラ、環境、アプリケーションなど）を整理するのに使用できます。

## プロジェクトのナビゲーション {#project-navigation}

プロジェクトを開くと、左のサイドバーの上部にプロジェクトの切り替え、その下にプロジェクトのすべてのセクションが表示されます。プロジェクト名の下には、このプロジェクトでの自分のロール（たとえば `task_runner`）が表示されます。ロールによって変更できるセクションが決まります。[チーム](./team)を参照してください。

![履歴タブが表示されたプロジェクトのダッシュボード](/assets/project-dashboard-history.webp)

| セクション | 含まれる内容 |
|---|---|
| **ダッシュボード** | [履歴](./projects/history)、[統計](./projects/stats)、[アクティビティ](./projects/activity) の各タブと、プロジェクトのオーナー向けの[設定](./projects/settings) |
| **タスクテンプレート** | 何をどのように実行するかの定義: [タスクテンプレート](./task-templates) |
| **ワークフロー** (Pro) | 承認と分岐を含むテンプレートのグラフ: [ワークフロー](./workflows) |
| **スケジュール** | テンプレートの cron 形式のスケジュール: [スケジュール](./schedules) |
| **インベントリ** | Ansible 用のホストと接続設定、Terraform 用のワークスペース: [インベントリ](./inventory) |
| **変数グループ** | タスクに注入される再利用可能な変数とシークレット: [変数グループ](./environment) |
| **キーストア** | 暗号化された認証情報と外部のシークレットストレージ: [キーストア](./key-store) |
| **リポジトリ** | playbook やスクリプトを含む Git リポジトリまたはローカルパス: [リポジトリ](./repositories) |
| **インテグレーション** | タスクを開始する受信 Webhook: [インテグレーション](./integrations) |
| **チーム** | メンバーとそのロール: [チーム](./team) |
| **ランナー** (Pro) | このプロジェクトに接続されたランナー: [プロジェクトのランナー](./projects/runners) |

サイドバーの下部には、ダークモードの切り替え、言語の切り替え、[アカウントメニュー](./account)があります。

## プロジェクトの作成 {#creating-a-project}

プロジェクトの作成は管理者が行えます。一般ユーザーは、サーバーのオプション `non_admin_can_create_project`（`SEMAPHORE_NON_ADMIN_CAN_CREATE_PROJECT`）が有効な場合にのみプロジェクトを作成できます。[設定](/admin-guide/configuration)を参照してください。

1. サイドバー上部のプロジェクト名をクリックし、**新しいプロジェクト** を選択します。
2. フォームに入力します。

| フィールド | 説明 |
|---|---|
| **プロジェクト名** | プロジェクトの表示名です。後から[設定](./projects/settings)で変更できます。 |
| **並列タスクの最大数** | 任意です。このプロジェクトのタスクを同時にいくつ実行できるかを指定します。制限しない場合は空のままにします。制限を超えたタスクは `waiting` のステータスでキューに待機します。 |
| **デモ** | 新しいプロジェクトにサンプルデータ（公開デモリポジトリ、インベントリ、キー、いくつかのタスクテンプレート）を登録します。何も設定せずに Semaphore を試したいときに使用します。 |

3. **作成** をクリックします。

プロジェクトを作成したユーザーは、そのプロジェクトの **オーナー** になります。

## プロジェクトの切り替え {#switching-between-projects}

サイドバー上部のプロジェクト名をクリックすると、自分がメンバーになっているすべてのプロジェクトが表示され、切り替えられます。最後に開いたプロジェクトはブラウザーに記憶されます。

## バックアップと復元 {#backup-and-restore}

プロジェクトは JSON ファイルにエクスポートし、同じ Semaphore インスタンスまたは別のインスタンスにインポートできます。

- **エクスポート**: **ダッシュボード → 設定** を開き、**プロジェクトのバックアップ** をクリックします（[設定](./projects/settings)を参照）。
- **インポート**: サイドバーのプロジェクト名をクリックし、**プロジェクトの復元** を選択して、バックアップファイルをアップロードします。

どちらの操作もコマンドラインからも実行できます。[CLI: プロジェクト](/admin-guide/cli/projects)を参照してください。

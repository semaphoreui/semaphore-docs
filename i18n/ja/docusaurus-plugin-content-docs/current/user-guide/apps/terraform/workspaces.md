
# ワークスペース

![テンプレートのワークスペースタブ](/assets/template-workspaces.webp)

Semaphore は Terraform のワークスペースを標準でサポートしており、1 つのプロジェクト内で複数の環境と構成を管理できます。この機能により、開発、ステージング、本番といった環境ごとに個別の状態ファイルを保持できます。

## 機能 {#features}

- **ワークスペースの管理**: Semaphore UI から直接ワークスペースを作成、切り替え、削除できます。
- **状態の分離**: 各ワークスペースは独自の状態ファイルを保持するため、環境間での競合を防げます。
- **環境変数**: ワークスペースごとの環境変数を設定できます。
- **ワークスペースの選択**: Terraform コマンドを実行する際に、対象のワークスペースを選択できます。

## Semaphore でのワークスペースの使用 {#using-workspaces-in-semaphore}

### ワークスペースの作成 {#creating-a-workspace}

ワークスペースを追加したい Terraform/OpenTofu テンプレートの **ワークスペース** セクションで、次の手順に従います。

1. ➕ ボタンをクリックします。  
2. 表示されたメニューで **新しいワークスペース** を選択します。  
3. モーダルダイアログでワークスペース名を入力し、モジュールのクローンに使用する SSH キーを選択します。  
4. **作成** ボタンをクリックして、新しいワークスペースをテンプレートに追加します。  
5. これで、このワークスペースを使用してタスクを実行できます。


### ワークスペースの切り替え {#switching-workspaces}

**既定にする** ボタンをクリックすると、Terraform/OpenTofu テンプレートの既定のワークスペースを設定できます。


### ワークスペースごとの変数 {#workspace-specific-variables}

Semaphore は現在、ワークスペースごとの変数をサポートしていません。

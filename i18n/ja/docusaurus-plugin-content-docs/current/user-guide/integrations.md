# インテグレーション

インテグレーションを使用すると、GitHub や GitLab などの外部サービスと Semaphore の間の連携を確立できます。

![インテグレーションの一覧](/assets/integrations-list.webp)

プロジェクトの Webhook URL は一覧の上に表示されます。各インテグレーションには名前と、起動するテンプレートがあります。インテグレーションをクリックすると、マッチャーと値の抽出ルールを設定できます。

![インテグレーションの詳細](/assets/integration-detail.webp)

インテグレーションを使用すると、専用のエンドポイント（エイリアス）を呼び出して特定のテンプレートをトリガーできます。エンドポイントには、次のいずれかの認証方式を設定できます。
* GitHub Webhooks
* トークン
* HMAC
* 認証なし

エイリアスは次の形式の URL を表します: `/api/integrations/<random_string>`。`GET` と `POST` のリクエストに対応しています。

## マッチャー {#matchers}

マッチャーでは、受信リクエストのパラメーターを定義できます。これらのパラメーターが一致すると、テンプレートが呼び出されます。

## 値の抽出ルール {#value-extractors}

抽出ルールを使用すると、リクエストのヘッダーまたはボディ（JSON フィールドまたは文字列）からデータを取得し、タスクに渡せます。抽出された各値には **変数の種類** があります。

* **環境変数**: 値がタスクの環境変数に追加され、変数グループの同名の変数を上書きします。
* **タスクパラメーター**: 値がタスクのパラメーター（たとえばサーベイ変数やプロンプト）になります。

## タスクパラメーター {#task-parameters}

インテグレーションは、パラメーター付きでタスクをトリガーできます。値の抽出ルールを使用してタスクパラメーター用の JSON ペイロードを構築し、プロンプトで渡される値を受け取れるようテンプレートを設定してください。

## エイリアスとマッチャーに関する注意 {#notes-on-aliases-and-matchers}

プロジェクトのエイリアス（インテグレーション一覧の上に表示される URL）は、そのプロジェクトのすべてのインテグレーションで共有されます。Semaphore は各インテグレーションのマッチャーを確認し、マッチャーが一致したテンプレートを起動します。インテグレーションは独自のエイリアスを持つこともでき、そのエイリアスへのリクエストでは、マッチャーを評価せずにそのインテグレーションが起動します。必要に応じてトークンまたは HMAC による認証を優先し、パラメーターは抽出ルールで渡してください。

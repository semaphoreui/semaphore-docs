# リファレンス

このセクションは、何が必要かはすでに分かっていて、正確な名前・型・デフォルト値を知りたいときのためのものです。ここでは何も説明しません。説明はガイドの役割です。

ここにあるページはリリースのたびに **Semaphore のソースコードから生成** されます。そのため、誰かが以前に表を書いたバージョンではなく、実際に動かしているバージョンを説明します。同じ理由から、これらのページは英語でのみ公開されます。翻訳したコピーは、オプションが一度変わっただけで古くなってしまうからです。

# Armazenamento de segredos no Devolutions Server <Enterprise />

O Semaphore UI oferece suporte ao Devolutions Server como armazenamento de segredos. 

![](/assets/dvls1.webp)

Você pode fornecer as seguintes opções:
- **URL do Devolutions Server** — endereço do seu servidor Devolutions.
- **Vault ID** — o identificador do vault onde os segredos são armazenados.
- **App Key** — a chave de aplicativo usada para autenticação.
- **Token** — token de autenticação. O token pode ser:
    - Armazenado no banco de dados.
    - Fornecido por meio de uma variável de ambiente.
    - Fornecido por meio de um arquivo.

O armazenamento pode funcionar em modo somente leitura.

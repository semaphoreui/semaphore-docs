
# Atividade

A página Atividade fornece uma trilha de auditoria completa de todas as ações e eventos que ocorrem no seu projeto. Este recurso registra as atividades dos usuários e os eventos do sistema, dando a você visibilidade total sobre o que está acontecendo no seu projeto.

![Atividade do projeto](/assets/project-activity.webp)

Cada linha mostra a hora, o usuário que executou a ação e uma descrição, por exemplo uma mudança de status de tarefa, uma atualização de template ou uma alteração na equipe. Os eventos são ordenados do mais recente para o mais antigo.

## Visão geral {#overview}

A página Atividade exibe um feed cronológico de todas as atividades do projeto, incluindo:

- Ações de usuários (criação, edição e exclusão de recursos)
- Eventos e notificações do sistema
- Alterações de acesso e permissões

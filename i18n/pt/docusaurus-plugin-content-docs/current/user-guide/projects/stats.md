# Estatísticas

A aba **Estatísticas** do dashboard do projeto mostra como as tarefas do projeto terminaram ao longo do tempo.

![Estatísticas do projeto](/assets/project-stats.webp)

O gráfico **Status das Tarefas** conta as tarefas por dia de acordo com o seu status final:

- **Sucesso**: a tarefa terminou sem erros.
- **Falha**: a tarefa terminou com um erro.
- **Parada**: a tarefa foi parada por um usuário.

Dois filtros acima do gráfico restringem os dados:

| Filtro | Opções |
|---|---|
| **Período** | Última semana, Último mês, Último ano |
| **Usuário** | Todos os usuários, ou um único membro do projeto. Tarefas iniciadas por agendamentos e integrações não têm usuário e são incluídas apenas em **Todos os usuários**. |

O mesmo gráfico está disponível para um único template na aba **Detalhes** da [página do template](../task-templates#template-page).

Para ver as execuções individuais em vez dos números agregados, use a aba [Histórico](./history).

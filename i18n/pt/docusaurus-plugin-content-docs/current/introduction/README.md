# Introdução

Esta seção é para qualquer pessoa que esteja conhecendo o Semaphore pela primeira vez, seja
para instalá-lo ou apenas para usá-lo. Ela responde às perguntas que vêm antes de qualquer procedimento:
o que o produto faz, do que é composta uma instalação, o que significam as palavras da interface
e o que você precisa ter à mão.

Leia-a uma vez, na ordem, e o restante da documentação deixa de precisar de explicação.
Nada aqui pede que você instale algo — [Primeiros passos](/getting-started) cuida
disso.

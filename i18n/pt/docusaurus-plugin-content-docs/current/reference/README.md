# Referência

Esta seção é para o momento em que você já sabe o que quer e precisa do nome, do tipo ou
do valor padrão exatos. Ela não explica nada; disso cuidam os guias.

As páginas daqui são **geradas a partir do código-fonte do Semaphore** a cada versão,
portanto descrevem a versão que você está executando, e não a versão para a qual alguém
escreveu uma tabela. Pelo mesmo motivo, elas são publicadas apenas em inglês: uma cópia
traduzida ficaria desatualizada na primeira vez que uma opção mudasse.

## Nesta seção {#in-this-section}

| Página | O que ela cobre |
|---|---|
| [Opções de configuração](/reference/configuration) | Cada chave do `config.json` com sua variável de ambiente, tipo e valor padrão. |
| [Referência da CLI](/reference/cli) | Cada comando, subcomando e flag do `semaphore`. |

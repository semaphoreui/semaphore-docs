# 레퍼런스

이 섹션은 무엇이 필요한지 이미 알고 있고 정확한 이름, 타입, 기본값이 필요한 순간을
위한 것입니다. 여기서는 아무것도 설명하지 않습니다. 설명은 가이드가 담당합니다.

여기 있는 페이지는 릴리스마다 **Semaphore 소스 코드에서 생성**되므로, 누군가 표를
작성했던 버전이 아니라 지금 실행 중인 버전을 설명합니다. 같은 이유로 이 페이지들은
영어로만 제공됩니다. 번역본은 옵션이 한 번만 바뀌어도 곧바로 낡은 내용이 되기
때문입니다.

## 이 섹션의 내용 {#in-this-section}

| 페이지 | 다루는 내용 |
|---|---|
| [설정 옵션](/reference/configuration) | `config.json`의 모든 키와 해당 환경 변수, 타입, 기본값. |
| [CLI 레퍼런스](/reference/cli) | `semaphore`의 모든 명령, 하위 명령, 플래그. |

# 레퍼런스

이 섹션은 무엇이 필요한지 이미 알고 있고 정확한 이름, 타입, 기본값이 필요한 순간을
위한 것입니다. 설명은 최소한으로만 합니다. 설명은 가이드가 담당합니다.

여기 있는 페이지 중 두 개는 **Semaphore 소스 코드에서 생성**되므로, 누군가 표를
작성했던 버전이 아니라 지금 실행 중인 버전을 설명합니다. 같은 이유로 이 페이지들은
영어로만 제공됩니다. 번역본은 옵션이 한 번만 바뀌어도 곧바로 낡은 내용이 되고,
아무도 그것을 알아차리지 못하기 때문입니다.

## 이 섹션의 내용 {#in-this-section}

| 페이지 | 다루는 내용 |
|---|---|
| [설정 옵션](/reference/configuration) | `config.json`의 모든 키와 해당 환경 변수, 타입, 기본값. 자동 생성됩니다. |
| [CLI](/reference/cli) | `semaphore` 명령: 각 명령 그룹이 하는 일, 설정 파일을 찾는 방식, 그리고 자동 생성된 모든 명령과 플래그 목록. |
| [API](/reference/api) | 토큰으로 인증하고 REST 엔드포인트를 호출하기. |

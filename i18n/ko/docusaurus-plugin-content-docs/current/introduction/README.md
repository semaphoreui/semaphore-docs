# 소개

이 섹션은 직접 설치하든 사용만 하든, Semaphore를 처음 만나는 모든 사람을 위한
것입니다. 어떤 절차보다도 먼저 떠오르는 질문에 답합니다. 제품이 무엇을 하는지,
배포는 무엇으로 이루어지는지, 인터페이스에 나오는 단어가 무엇을 뜻하는지,
무엇을 준비해 두어야 하는지를 다룹니다.

순서대로 한 번만 읽으면, 나머지 문서는 더 이상 설명이 필요하지 않습니다.
여기서는 아무것도 설치하지 않습니다 — 설치는 [시작하기](/getting-started)에서
다룹니다.

# 호스트 <FeatureState feature="hosts" />

관리자용 **Hosts** 페이지에는 모든 프로젝트의 호스트가 한곳에 표시되며, 그중 어떤 호스트가 라이선스의 **Nodes**로 계산되는지 보여 줍니다. 왼쪽 아래의 관리자 메뉴를 열고 **Hosts**를 선택합니다.

호스트가 목록에 들어오는 방식, 상태, 검색, 호스트 카드는 프로젝트 페이지와 같습니다. 자세한 내용은 [호스트](/user-guide/hosts)를 참고하십시오. 여기서는 호스트가 모든 프로젝트에 걸쳐 한 행으로 표시되며, 카드에는 해당 호스트에 접속한 프로젝트와 작업이 나열됩니다.

## 라이선스 카운트 {#license-count}

라이선스에는 일정 수의 호스트가 포함됩니다. **구독 및 결제**의 **Nodes** 행에는 사용 중인 수가 `42 / 50`처럼 표시됩니다. 지난달 이내에 Ansible 작업이 접속했고 아무도 폐기하지 않은 호스트가 사용 중인 호스트입니다. 한 번도 접속되지 못한 호스트는 사용 중이 아닙니다.

사용 중이 아닌 호스트는 목록에 **Not counted**로 표시됩니다. 다음에 작업이 접속하면 자동으로 카운트에 다시 포함됩니다.

사용 중인 호스트가 라이선스에 포함된 수보다 많으면 **Nodes** 행이 빨간색으로 바뀌며 **(limit exceeded)**가 표시되고, 이 페이지에 경고가 나타납니다. 더 이상 관리하지 않는 호스트를 폐기하거나 라이선스를 확장하십시오. 자세한 내용은 [라이선스 활성화](/admin-guide/license)를 참고하십시오.

## 호스트 폐기 {#decommission}

인프라에서 호스트를 제거했다면 해당 행 끝의 **Decommission**을 클릭하고 확인합니다. 호스트는 즉시 카운트에서 빠지고 **Decommissioned**로 표시되며, 모든 프로젝트에서 기록이 유지됩니다. 나중에 작업이 다시 해당 호스트에 접속하면 Semaphore가 표시를 제거하고 호스트는 다시 사용 중이 됩니다.

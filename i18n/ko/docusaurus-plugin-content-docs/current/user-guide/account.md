# 내 계정

개인 설정은 사이드바 하단의 계정 메뉴에 있습니다. 이름을 클릭하면 열립니다.

![계정 메뉴](/assets/user-menu.webp)

| 항목 | 설명 |
|---|---|
| 버전 | 서버에서 실행 중인 Semaphore UI 버전입니다. |
| **API 토큰** | [REST API](/reference/api)용 개인 토큰입니다. |
| **계정 편집** | 이름, 사용자 이름, 이메일, 알림 설정, 비밀번호입니다. |
| **로그아웃** | 세션을 종료합니다. |

메뉴 옆에는 **다크 모드** 스위치와 **언어** 전환기가 있습니다. 두 설정은 모두 브라우저에 저장됩니다.

## 계정 편집 {#edit-account}

![계정 편집 대화 상자](/assets/account-edit.webp)

**설정** 탭에는 다음 항목이 있습니다:

| 필드 | 설명 |
|---|---|
| **이름** | 작업 기록과 활동에 표시되는 표시 이름입니다. |
| **사용자 이름** | 로그인 이름입니다. |
| **이메일** | 이메일 알림과 비밀번호 복구에 사용되는 주소입니다. |
| **알림 보내기** | 작업에 대한 이메일 알림을 받습니다. 알림은 [이메일 채널](/admin-guide/notifications/email)이 설정되어 있고 프로젝트가 알림을 허용하는 경우에만 전송됩니다. |

체크박스 옆의 배지는 전역 플래그를 나타냅니다: Pro 인스턴스에서는 **Pro 사용자**, 관리자는 **Admin**, LDAP 또는 OpenID Connect로 관리되는 계정은 **External**로 표시됩니다. 외부 사용자는 여기에서 사용자 이름이나 비밀번호를 변경할 수 없습니다.

**보안** 탭에서는 비밀번호를 변경할 수 있습니다. 관리자가 시간 기반 일회용 비밀번호를 활성화한 경우 같은 탭에서 2차 인증 요소를 설정합니다.

![보안 탭](/assets/account-security.webp)

## API 토큰 {#api-tokens}

계정 메뉴에서 **API 토큰**을 선택합니다. 이 페이지에는 토큰 목록이 생성 날짜, 만료 날짜, 상태와 함께 표시됩니다. **API Reference** 링크를 클릭하면 인스턴스에 내장된 Swagger UI가 열립니다.

![API 토큰](/assets/api-tokens.webp)

**새 토큰**을 클릭하고 토큰 이름을 지정한 후 만료 시점을 선택합니다. 토큰 값은 생성 후 한 번만 표시되므로 즉시 복사하십시오.

![새 토큰 대화 상자](/assets/api-token-new.webp)

토큰은 `Authorization: Bearer` 헤더에 사용합니다. [API](/reference/api)를 참조하십시오. 토큰을 취소하려면 목록에서 삭제하십시오.

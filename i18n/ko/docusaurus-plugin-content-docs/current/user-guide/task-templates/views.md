# 뷰

뷰는 작업 템플릿을 템플릿 목록 위쪽의 탭으로 그룹화합니다. 프로젝트는 **All** 뷰 하나로 시작하며, 예를 들어 **Build**, **Deploy**, **Tools**처럼 직접 뷰를 추가할 수 있습니다. 이를 통해 템플릿이 많은 프로젝트에서도 사용자가 원하는 템플릿을 빠르게 찾을 수 있습니다.

![뷰 탭이 있는 템플릿 목록](/assets/templates-list.webp)

## 뷰 관리 {#managing-views}

**Manager** 역할 이상의 사용자가 뷰를 편집할 수 있습니다. 뷰 탭 옆의 연필 아이콘을 클릭하여 **Edit views** 대화 상자를 열고, **Add view**를 사용하여 새 탭을 만듭니다. 각 뷰에는 다음 설정이 있습니다:

| 설정 | 설명 |
|---|---|
| **Title** | 탭 레이블입니다. |
| **Type** | **Custom**은 이 뷰에 할당된 템플릿만 표시합니다. **All**은 프로젝트의 모든 템플릿을 표시합니다. |
| **Sort by** 및 **Reverse** | 탭에 표시되는 템플릿의 기본 정렬 순서입니다. |
| **Hidden** | 뷰는 유지하되 탭을 숨깁니다. |

대화 상자에서 뷰를 끌어다 놓아 탭 순서를 변경할 수 있습니다. 뷰를 삭제해도 해당 템플릿은 삭제되지 않으며, **All** 뷰에 계속 표시됩니다.

## 템플릿을 뷰에 할당 {#assigning-a-template-to-a-view}

템플릿 양식을 열고 **View** 필드에서 탭을 선택합니다. 템플릿은 한 번에 하나의 사용자 정의 뷰에만 속하며, **All** 유형의 뷰에는 항상 표시됩니다.

## 열 {#columns}

템플릿 목록 오른쪽 상단의 톱니바퀴 아이콘을 클릭하면 열 선택기가 열립니다. 이 설정은 모든 뷰에 적용되며 브라우저에 저장됩니다.

# 프로젝트

프로젝트는 Semaphore UI에서 분리의 기본 단위입니다. 작업 템플릿, 작업, 인벤토리, 변수 그룹, 키, 리포지토리, 통합, 스케줄, 러너, 팀 멤버 등 여러분이 다루는 모든 리소스는 정확히 하나의 프로젝트에 속합니다.

프로젝트는 서로 독립적이므로, 단일 Semaphore 설치 내에서 서로 관련 없는 시스템을 정리하는 데 사용할 수 있습니다. 예를 들어 서로 다른 팀, 인프라, 환경 또는 애플리케이션을 구분할 수 있습니다.

## 프로젝트 탐색 {#project-navigation}

프로젝트를 열면 왼쪽 사이드바 상단에 프로젝트 전환기가 표시되고 그 아래에 모든 프로젝트 섹션이 표시됩니다. 프로젝트 이름 아래에는 이 프로젝트에서의 역할(예: `task_runner`)이 표시됩니다. 역할은 변경할 수 있는 섹션을 결정합니다. [팀](./team)을 참조하십시오.

![History 탭이 표시된 프로젝트 대시보드](/assets/project-dashboard-history.webp)

| 섹션 | 포함된 내용 |
|---|---|
| **대시보드** | [기록](./projects/history), [통계](./projects/stats), [활동](./projects/activity) 탭과, 프로젝트 소유자를 위한 [설정](./projects/settings) 탭 |
| **작업 템플릿** | 무엇을 어떻게 실행할지에 대한 정의: [작업 템플릿](./task-templates) |
| **워크플로**(Pro) | 승인과 분기를 포함하는 템플릿 그래프: [워크플로](./workflows) |
| **스케줄** | 템플릿을 위한 cron 형태의 스케줄: [스케줄](./schedules) |
| **인벤토리** | Ansible을 위한 호스트 및 연결 설정, Terraform을 위한 워크스페이스: [인벤토리](./inventory) |
| **변수 그룹** | 작업에 주입되는 재사용 가능한 변수와 시크릿: [변수 그룹](./environment) |
| **키 저장소** | 암호화된 자격 증명과 외부 시크릿 저장소: [키 저장소](./key-store) |
| **리포지토리** | 플레이북과 스크립트가 있는 Git 리포지토리 또는 로컬 경로: [리포지토리](./repositories) |
| **통합** | 작업을 시작하는 수신 웹훅: [통합](./integrations) |
| **팀** | 멤버와 그 역할: [팀](./team) |
| **러너**(Pro) | 이 프로젝트에 연결된 러너: [프로젝트 러너](./projects/runners) |

사이드바 하단에는 다크 모드 스위치, 언어 전환기, [계정 메뉴](./account)가 있습니다.

## 프로젝트 생성 {#creating-a-project}

프로젝트 생성은 관리자가 사용할 수 있습니다. 일반 사용자는 서버 옵션 `non_admin_can_create_project`(`SEMAPHORE_NON_ADMIN_CAN_CREATE_PROJECT`)가 활성화된 경우에만 프로젝트를 생성할 수 있습니다. [설정](/admin-guide/configuration)을 참조하십시오.

1. 사이드바 상단의 프로젝트 이름을 클릭하고 **새 프로젝트**를 선택합니다.
2. 양식을 입력합니다:

| 필드 | 설명 |
|---|---|
| **프로젝트 이름** | 프로젝트의 표시 이름입니다. 나중에 [설정](./projects/settings)에서 변경할 수 있습니다. |
| **최대 동시 작업 수** | 선택 사항입니다. 이 프로젝트의 작업이 동시에 몇 개까지 실행될 수 있는지 지정합니다. 제한을 두지 않으려면 비워 두십시오. 제한을 초과한 작업은 `waiting` 상태로 큐에서 대기합니다. |
| **데모** | 새 프로젝트를 샘플 데이터로 채웁니다: 공개 데모 리포지토리, 인벤토리, 키, 여러 작업 템플릿이 포함됩니다. 아무것도 설정하지 않고 Semaphore를 체험해 보려면 사용하십시오. |

3. **생성**을 클릭합니다.

프로젝트를 생성한 사용자는 해당 프로젝트의 **소유자**가 됩니다.

## 프로젝트 간 전환 {#switching-between-projects}

사이드바 상단의 프로젝트 이름을 클릭하면 자신이 멤버로 속한 모든 프로젝트를 확인하고 전환할 수 있습니다. 마지막으로 열었던 프로젝트는 브라우저에 기억됩니다.

## 백업 및 복원 {#backup-and-restore}

프로젝트를 JSON 파일로 내보내고 동일한 또는 다른 Semaphore 인스턴스로 가져올 수 있습니다:

- **내보내기**: **대시보드 → 설정**을 열고 **프로젝트 백업**을 클릭합니다([설정](./projects/settings) 참조).
- **가져오기**: 사이드바에서 프로젝트 이름을 클릭하고 **프로젝트 복원**을 선택한 후 백업 파일을 업로드합니다.

두 작업 모두 명령줄에서도 사용할 수 있습니다. [CLI: 프로젝트](/reference/cli/projects)를 참조하십시오.

# 통계

프로젝트 대시보드의 **통계** 탭은 프로젝트의 작업이 시간 경과에 따라 어떻게 완료되었는지 보여 줍니다.

![프로젝트 통계](/assets/project-stats.webp)

**작업 상태** 차트는 일별로 최종 상태에 따라 작업 수를 집계합니다:

- **Success**: 작업이 오류 없이 완료되었습니다.
- **Failed**: 작업이 오류로 종료되었습니다.
- **Stopped**: 작업이 사용자에 의해 중지되었습니다.

차트 위의 두 가지 필터로 데이터 범위를 좁힐 수 있습니다:

| 필터 | 옵션 |
|---|---|
| **기간** | 지난 주, 지난 달, 지난 해 |
| **사용자** | 모든 사용자 또는 프로젝트의 단일 멤버입니다. 스케줄과 통합으로 시작된 작업에는 사용자가 없으므로 **모든 사용자**에만 포함됩니다. |

동일한 차트는 [템플릿 페이지](../task-templates#template-page)의 **Details** 탭에서 개별 템플릿에 대해서도 확인할 수 있습니다.

집계된 수치가 아니라 개별 실행 내역을 보려면 [기록](./history) 탭을 사용하십시오.

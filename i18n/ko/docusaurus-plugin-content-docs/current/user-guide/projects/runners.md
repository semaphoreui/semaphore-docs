# 프로젝트 러너 <Pro />

러너는 Semaphore 서버가 아닌 다른 머신에서 작업을 실행합니다. 대상 인프라에 더 가까운 위치, 다른 네트워크 영역, 또는 다른 툴체인을 갖춘 환경에서 실행할 수 있습니다. **전역 러너**는 관리자가 등록하며 모든 프로젝트에 제공됩니다. **프로젝트 러너**는 하나의 프로젝트에 속하며 **러너** 섹션에서 해당 팀이 관리합니다.

![프로젝트 러너](/assets/project-runners-list.webp)

| 열 | 내용 |
|---|---|
| 스위치 | 러너를 활성화하거나 비활성화합니다. 비활성화된 러너는 작업을 받지 않습니다. 스위치는 프로젝트 러너에만 있으며, 전역 러너는 관리자가 관리합니다. |
| **이름** | 러너 이름입니다. **Global** 배지는 모든 프로젝트가 공유하는 러너를 나타냅니다. |
| **태그** | 러너의 태그입니다. **러너 태그**가 지정된 템플릿은 해당 태그를 가진 러너에서만 실행됩니다. |
| **상태** | 러너가 최근에 서버를 폴링했으면 **Online**, 그렇지 않으면 **Offline**입니다. |

## 러너 추가 {#adding-a-runner}

**Manager** 역할 이상이 필요합니다. **새 러너**를 클릭하고 양식을 입력하십시오.

<div class="DialogScreenshot DialogScreenshot--small">

![새 러너 대화 상자](/assets/project-runner-new.webp)

</div>

| 필드 | 설명 |
|---|---|
| **이름** | 목록과 작업 상세 정보에 표시되는 러너 이름입니다. |
| **태그** | 선택 사항입니다. 하나 이상의 태그입니다. **러너 태그**가 지정된 템플릿은 해당 태그를 가진 러너만 실행합니다. |
| **기본값 여부** | 이 플래그가 설정된 러너는 러너 태그가 없는 템플릿의 작업도 수행합니다. 이 플래그도 없고 태그도 없는 러너는 작업을 전혀 받지 않습니다. |
| **등록** | 선택한 경우: 러너가 등록된 상태로 생성되며, 대화 상자에 러너 설정에 입력할 러너 토큰이 표시됩니다. 선택하지 않은 경우: 러너가 등록되지 않은 상태로 생성되고 일회용 **등록 토큰**을 받게 되며, 러너는 `semaphore runner register` 또는 `semaphore runner start --auto-register`로 직접 등록합니다. |
| **웹훅** | 선택 사항입니다. 작업이 러너에 할당될 때 Semaphore가 호출하는 URL입니다. 예를 들어 클라우드 함수와 함께 온디맨드(일회성) 러너를 시작하는 데 사용합니다. |
| **최대 동시 작업 수** | 선택 사항입니다. 러너가 동시에 실행할 수 있는 작업 수입니다. |
| **활성화** | 러너가 작업을 받을지 여부입니다. |

생성 후 러너를 클릭하면 토큰이나 등록 토큰을 다시 확인하고 설정 스니펫을 복사할 수 있습니다.

## 러너 설치 {#installing-the-runner}

러너는 동일한 `semaphore` 바이너리 또는 러너 모드로 시작한 `semaphoreui/runner` Docker 이미지입니다. 설치, 설정 파일, 등록 명령, 익스큐터(local, Docker, Kubernetes), 보안에 대한 내용은 관리자 가이드에 설명되어 있습니다: [러너](/admin-guide/runners) 및 [CLI: 러너](/reference/cli/runners).

## 러너로 작업 라우팅 {#routing-tasks-to-runners}

1. 러너에 하나 이상의 **태그**를 부여합니다. 예: `windows-qa-server`.
2. 템플릿 양식에서 **러너 태그**를 같은 값으로 설정합니다.
3. 해당 태그를 가진 러너가 온라인이 될 때까지 템플릿의 작업은 `waiting` 상태로 대기합니다.

러너 태그가 없는 템플릿은 전역 기본 러너를 포함해 **기본값 여부**가 설정된 러너로 전달됩니다. 작업을 실행한 러너는 [작업 창](../tasks#task-window)의 **Details** 탭에 표시됩니다.

## 보안 {#security}

- 러너가 서버에 연결하며 그 반대 방향으로는 연결하지 않으므로, 러너는 NAT 뒤나 사설 네트워크에 둘 수 있습니다.
- 러너의 모든 요청은 해당 토큰으로 인증됩니다. 러너를 취소하려면 삭제하거나 비활성화하십시오.
- 러너와 서버 간에는 HTTPS를 사용하십시오. [네트워크 보안](/admin-guide/security/network)을 참조하십시오.

# 설정

프로젝트 대시보드의 **설정** 탭은 프로젝트 **소유자**가 사용할 수 있습니다. 여기에는 일반 프로젝트 옵션과 되돌릴 수 없는 작업이 포함됩니다.

![프로젝트 설정](/assets/project-settings-general.webp)

## 일반 {#general}

| 필드 | 설명 |
|---|---|
| **프로젝트 이름** | 프로젝트 전환기와 알림에 표시되는 표시 이름입니다. |
| **최대 동시 작업 수** | 선택 사항입니다. 이 프로젝트의 작업이 동시에 실행될 수 있는 최대 개수입니다. 제한을 두지 않으려면 비워 두십시오. 제한을 초과한 작업은 빈 슬롯이 생길 때까지 `waiting` 상태로 큐에 남아 있습니다. |
| **Telegram Chat ID** | 선택 사항입니다. 전역으로 설정된 채팅이 아닌 다른 Telegram 채팅으로 이 프로젝트의 알림을 보냅니다. [Telegram 알림](/admin-guide/notifications/telegram#per-project-chat-ids)을 참조하십시오. |
| **이 프로젝트의 알림 허용** | 알림의 마스터 스위치입니다. 이 옵션이 꺼져 있으면 서버에 채널이 설정되어 있더라도 이 프로젝트의 작업에 대한 알림을 어떤 채널도 보내지 않습니다. |

**테스트 알림**은 설정된 모든 [알림 채널](/admin-guide/notifications)로 테스트 메시지를 보내므로, 작업을 실행하지 않고도 서버 설정을 검증할 수 있습니다. **저장**을 클릭하면 변경 사항이 적용됩니다.

## 위험 구역 {#danger-zone}

| 작업 | 결과 |
|---|---|
| **프로젝트 백업** | 프로젝트 정의가 담긴 JSON 파일을 다운로드합니다: 템플릿, 인벤토리, 변수 그룹, 키(비밀 값 제외), 리포지토리, 스케줄, 뷰, 통합이 포함됩니다. **새 프로젝트 → 프로젝트 복원** 또는 [`semaphore projects import`](/reference/cli/projects)로 복원하십시오. |
| **캐시 지우기** | 서버에 있는 프로젝트의 모든 캐시 파일(예: 복제된 리포지토리)을 삭제합니다. 다음 작업에서 리포지토리를 다시 복제합니다. 이 작업은 되돌릴 수 없습니다. |
| **프로젝트 삭제** | 프로젝트와 그 모든 리소스 및 작업 기록을 삭제합니다. 되돌릴 수 없습니다. |

## 관련 설정 {#related-settings}

- 프로젝트에 연결된 러너와 러너 태그: [프로젝트 러너](./runners)
- 알림 채널은 서버에서 설정합니다: [알림](/admin-guide/notifications)

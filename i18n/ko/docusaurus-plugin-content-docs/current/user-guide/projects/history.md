# 기록

프로젝트 대시보드의 **기록** 탭에는 프로젝트의 모든 작업이 최신 순으로 나열됩니다. 프로젝트를 열었을 때 표시되는 기본 화면입니다.

![프로젝트 기록](/assets/project-dashboard-history.webp)

## 열 {#columns}

| 열 | 내용 |
|---|---|
| **작업** | 작업 번호, 작업이 생성된 템플릿, 사용된 리포지토리 리비전의 커밋 메시지입니다. 왼쪽의 아이콘은 애플리케이션(Ansible, Terraform, Bash 등)을 나타냅니다. |
| **버전** | [빌드 및 배포 템플릿](../task-templates/build-deploy)의 경우: 빌드되거나 배포된 버전입니다. 다른 템플릿의 경우 상태 아이콘만 표시됩니다. |
| **상태** | 현재 상태 배지입니다. [작업 상태](../tasks#task-statuses)를 참조하십시오. |
| **사용자** | 작업을 시작한 사용자입니다. 스케줄이나 통합으로 시작된 작업에는 사용자가 없습니다. |
| **시작** | 브라우저 시간대를 기준으로 한 시작 날짜와 시간입니다. |
| **소요 시간** | 작업이 실행된 시간입니다. |

목록은 페이지로 나뉩니다. 작업 번호나 템플릿 이름을 클릭하면 로그, 상세 정보, 요약이 포함된 [작업 창](../tasks#task-window)이 열립니다. 작업 창 헤더의 템플릿 이름을 클릭하면 템플릿 페이지로 이동합니다.

## 작업 보관 {#task-retention}

기본적으로 모든 작업과 해당 로그는 영구적으로 보관됩니다. 템플릿별 기록을 제한하려면 `config.json`에 `max_tasks_per_template`을 설정하거나 `SEMAPHORE_MAX_TASKS_PER_TEMPLATE` 환경 변수를 사용하십시오:

```json
{
  "max_tasks_per_template": 30
}
```

제한에 도달하면 해당 템플릿의 가장 오래된 작업이 로그와 함께 삭제됩니다. 전체 옵션 목록은 [설정](/admin-guide/configuration)을 참조하십시오.

# 호스트 <FeatureState feature="hosts" />

프로젝트의 **Hosts** 페이지에는 해당 프로젝트의 Ansible 작업이 접속한 모든 호스트가 마지막 실행 결과와 함께 표시됩니다. 작업 로그를 하나씩 열지 않고도 실패하는 호스트, 접속할 수 없는 호스트, 한동안 어떤 작업도 접속하지 않은 호스트를 확인할 수 있습니다.

## 동작 방식 {#how-it-works}

호스트를 직접 추가하지 않습니다. Ansible 작업이 끝날 때마다 Semaphore는 플레이의 각 호스트와 해당 호스트에서의 결과(`ok`, `changed`, `failed`, `unreachable`)를 기록합니다. 서버, 러너, Docker 및 Kubernetes 실행기에서 실행한 작업이 모두 포함됩니다. Terraform이나 Bash 같은 다른 애플리케이션의 작업은 호스트를 추가하지 않습니다.

호스트는 인벤토리의 이름으로 식별됩니다. 두 인벤토리의 `web-01`은 하나의 호스트이며, `Web-01`은 `web-01`과 같은 호스트입니다. 여러 프로젝트의 작업이 접속하는 호스트는 각 프로젝트에 해당 프로젝트 고유의 수치로 표시됩니다. 호스트가 인벤토리에서 빠져도 기록과 함께 목록에 남아 있습니다.

## 호스트 찾기 {#find-a-host}

- **Search**는 이름으로 호스트를 찾습니다.
- **Failing now**는 마지막 실행이 실패한 호스트를 표시합니다. **Unreachable**은 Ansible이 연결하지 못한 호스트를 표시합니다. **Not seen 30 days**는 한 달 동안 어떤 작업도 접속하지 않은 호스트를 표시합니다.
- **Template**은 목록을 하나의 템플릿의 호스트로 좁힙니다.

호스트를 클릭하면 카드가 열립니다. 처음 확인된 시점, 실행 횟수, 최근 10회 실행 중 실패한 횟수, 해당 호스트에 접속한 작업과 이 호스트에서의 결과가 표시됩니다. 작업을 클릭하면 해당 로그가 열립니다.

작업의 **Summary** 탭에서는 한 번의 실행에 대해 같은 내용을 볼 수 있습니다. **All servers**를 선택하면 해당 작업의 모든 호스트가 카운터와 함께 표시됩니다.

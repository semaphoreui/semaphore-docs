
# 워크스페이스

![템플릿의 워크스페이스 탭](/assets/template-workspaces.webp)

Semaphore는 Terraform 워크스페이스를 기본적으로 지원하므로, 단일 프로젝트 내에서 여러 환경과 설정을 관리할 수 있습니다. 이 기능을 사용하면 개발, 스테이징, 프로덕션과 같이 서로 다른 환경에 대해 별도의 상태 파일을 유지할 수 있습니다.

## 기능 {#features}

- **워크스페이스 관리**: Semaphore UI에서 직접 워크스페이스를 생성, 전환, 삭제합니다.
- **상태 격리**: 각 워크스페이스는 고유한 상태 파일을 유지하여 환경 간 충돌을 방지합니다.
- **환경 변수**: 워크스페이스별 환경 변수를 설정합니다.
- **워크스페이스 선택**: Terraform 명령을 실행할 때 대상 워크스페이스를 선택합니다.

## Semaphore에서 워크스페이스 사용 {#using-workspaces-in-semaphore}

### 워크스페이스 생성 {#creating-a-workspace}

워크스페이스를 추가하려는 Terraform/OpenTofu 템플릿의 **워크스페이스** 섹션에서 다음 단계를 따르십시오:

1. ➕ 버튼을 클릭합니다.  
2. 표시되는 메뉴에서 **새 워크스페이스**를 선택합니다.  
3. 모달 대화 상자에서 워크스페이스 이름을 입력하고 모듈을 복제할 때 사용할 SSH 키를 선택합니다.  
4. **생성** 버튼을 클릭해 새 워크스페이스를 템플릿에 추가합니다.  
5. 이제 이 워크스페이스를 사용해 작업을 실행할 수 있습니다.


### 워크스페이스 전환 {#switching-workspaces}

**MAKE DEFAULT** 버튼을 클릭하여 Terraform/OpenTofu 템플릿의 기본 워크스페이스를 설정할 수 있습니다.


### 워크스페이스별 변수 {#workspace-specific-variables}

Semaphore는 현재 워크스페이스별 변수를 지원하지 않습니다.
